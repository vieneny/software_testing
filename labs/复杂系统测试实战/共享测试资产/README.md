# 共享测试资产

本目录提供两个实战项目共同使用的契约、场景和可执行验收入口：

- [系统间接口契约](系统间接口契约.md)：跨语言错误、关联 ID、AI Schema 和幂等约定；
- [端到端业务场景](端到端业务场景.md)：目标业务故事与风险；
- [全链路验收指南](全链路验收指南.md)：本地启动三个服务并执行黑盒验收；
- `全链路接口验收.py`：只用 Python 标准库和合成数据运行的接口验收脚本。

这里只放两个系统可以共同使用的**通用契约与合成场景**，不放业务实现。

## 内容

- [系统间接口契约](系统间接口契约.md)：跨语言 HTTP、错误、request id、AI 降级；
- [端到端业务场景](端到端业务场景.md)：两个系统的核心验收旅程；
- 后续可增加公开/合成 OpenAPI、JSON Schema、Postman/Hurl、k6 和 Playwright 资产。

## 规则

1. 测试数据使用 `example.test` 域名、虚构姓名和不可路由号码；
2. Token、Cookie、Prompt、Trace 和日志样例不得含真实密钥；
3. 契约修改先兼容消费者，再升级 Provider；
4. 共享的是协议和测试方法，不共享两个系统的数据库；
5. AI 输出永远不是“服务执行成功”的唯一证据。
