这个阶段用于检验前面各阶段是否真正形成能力，不替代功能、接口、UI、性能、质量工程或 AI 测试实践。

4. [软件测试面试题库](./04-面试题库/README.md)

## 离线题库

直接双击打开：

```text
apps/interview-bank/offline/软件测试离线题库.html
```

无需安装 Python、Node.js 或启动服务。支持关键词、模块、来源、收藏和每页条数；学习记录保存在当前浏览器。

## 使用方式

```text
按岗位选择模块
  → 先脱稿回答
  → 查看答题思路与详解
  → 回到对应学习阶段补实验
  → 再次限时回答
  → 记录追问和改进
```

## 完成证据

- [ ] 作品中的每项能力都有代码、测试或报告证据；
- [ ] 能区分个人真实经历与公开练习项目；
- [ ] 每道题按结论、依据、行动、证据、边界回答；
- [ ] 至少完成三次按岗位组织的模拟面试；
- [ ] 错题能映射回具体学习阶段，而不是只背文字。
