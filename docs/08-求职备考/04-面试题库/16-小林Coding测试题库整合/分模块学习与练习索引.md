# 分模块学习与练习索引

## 一、小白起步路线

建议先建立测试分析能力，再学习工具：

1. 测试目的、风险、缺陷、回归和发布结论；
2. 等价类、边界值、判定表、状态迁移和探索式测试；
3. Web 登录、购物车、文件下载与接口分层断言；
4. HTTP、SQL、Linux 和 Git 基础；
5. 进入自动化或性能专项。

本轮优先练习：

- `xiaolin-business-session-based-exploration`
- `xiaolin-business-web-login-state-security`
- `xiaolin-business-cart-merge-pricing`
- `xiaolin-business-download-api`

回答时必须说明范围、风险、用例、证据和残余风险，不能只罗列测试点。

## 六、面试练习方法

每道题进行三轮：

1. **两分钟口述**：结论、原因和主要步骤；
2. **五分钟追问**：失败怎么办、如何证明、替代方案、适用边界；
3. **一次实操**：在可控练习环境中产生证据。

自评维度：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 正确性 | 有明显错误 | 基本正确但有遗漏 | 正确且条件明确 |
| 可执行性 | 只背名词 | 有步骤但不完整 | 能直接形成测试计划 |
| 证据 | 没有证据 | 只提工具名 | 指标、日志、Trace、数据可复核 |
| 边界 | 绝对化 | 能说一个限制 | 能比较替代方案和残余风险 |
| 真实性 | 编造经历 | 场景表述含糊 | 明确公开/合成练习与真实经历边界 |

满分 10 分。连续两次达到 8 分以上，并完成对应实操后，再标记为“掌握”。
