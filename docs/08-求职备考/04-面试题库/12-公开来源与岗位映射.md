## 一、证据使用顺序

题库采用四层证据：

1. **标准、规范和官方研究**：用于解释稳定原理与风险框架；
2. **工具官方文档和官方仓库**：用于核对当前行为、配置和维护状态；
3. **公开招聘岗位样本**：用于观察企业正在表达的职责组合；
4. **公开社区面试题库**：只用于发现常见提问方式，答案必须回到前三类证据或实验核验。

完整的市场研究方法和报告数据见[市场需求与技术选型](../../00-学习指南/02-市场需求与技术选型.md)及[软件测试与人工智能测试招聘需求调研](../../00-学习指南/04-软件测试与人工智能测试招聘需求调研.md)。当前招聘底座为 2026-07-27 的 BOSS 直聘公开岗位快照。

## 三、社区题库如何使用

社区题库适合观察面试官的提问形式，但不直接复制答案。

- [牛客测试工程师近期面经聚合](https://www.nowcoder.com/experience/680) 在 2026-07-20 至 07-24 的公开样本中反复出现项目深挖、AI/RAG/Agent、自动化工程、SQL/算法和现场场景；
- [牛客 AI 测试实习面经公开页](https://www.nowcoder.com/feed/main/detail/6d71aa3fed4d4f45b2e6c307a308023c) 提供了 AI 生成内容评测、RAG、Trace、隐私与传统场景题的候选方向；
- [牛客 Harness Engineering 面经公开页](https://www.nowcoder.com/feed/main/detail/01b2ab3205fb4c69ba2aa6e1d32b2e7e) 提供了接口/UI 自动化、AI 工具使用和现场工程设计的候选方向；
- [小红书“软件测试面试”站内搜索](https://www.xiaohongshu.com/search_result?keyword=软件测试面试) 于 2026-07-29 在用户已登录浏览器中核对，近期题型涉及 App 性能与兼容、ADB、pytest、接口关联、UI 自动化维护和项目追问；
- 小红书“AI测试面试”近期结果反复涉及 AI 生成用例、稳定定位、Prompt、RAG 指标、非确定性、安全、Python 实操和 CI。站内笔记链接含临时访问参数，因此仓库不保存作者、账号、评论、图片或 `xsec_token`，只保留转述后的题型趋势；
- [小林 Coding 测试开发面试题全攻略](https://xiaolincoding.com/interview/test_dev.html) 于 2026-04-28 更新，可用于检查业务测试、Java/Python 自动化和性能分类是否缺项；本仓库不复制其答案；
- [Candidate Interview Evaluation Template](https://gist.github.com/limkhashing/b5aebbc1affe8752af1f756cfa196c2d) 将一次面试拆成经历、测试深挖、技术和行为问题，可用于设计本仓库的模拟面试；
- [AI Engineering Interview Questions](https://github.com/amitshekhariitbhu/ai-engineering-interview-questions) 收录了 RAG、Agent、评测、安全和生产治理方向的问题，可作为 AI 专题候选题来源；
- [awesome-ai-testing](https://github.com/tugkanboz/awesome-ai-testing) 汇总公开 AI 测试工具，可用于发现实验对象，不能用工具列表代替方法论；
- [LangSmith Cookbook：Testing & Evaluation](https://github.com/langchain-ai/langsmith-cookbook/tree/main/testing-examples) 提供公开评测实验思路。

### 本轮从趋势到原创题的转换

| 社区反复出现的问法 | 本仓库重构后的能力题 | 核验依据 |
|---|---|---|
| HTTP 200 是否算成功 | 协议、Schema、业务码和副作用四层断言 | RFC 9110、公开 API 契约 |
| Playwright 元素偶发找不到 | 用 Trace、DOM、网络和控制台做故障分类 | Playwright 官方文档 |
| Android/iOS 自动化能否复用 | 业务层复用与平台适配层边界 | Appium 官方文档 |
| AI 能否生成测试用例 | 可用率、风险召回、返工成本与泄漏控制 | ISTQB CT-AI、人工基线实验 |
| RAG 回答错误怎么查 | 检索、上下文、生成与引用分层定位 | RAG 可观察 Trace、配对实验 |
| Agent 工具超时怎么办 | 幂等、结果未知、状态查询、补偿和审计 | 分布式不变量、OWASP AI 安全 |
| 覆盖率 98% | 分母、时间窗、首次失败、未覆盖风险和收益 | 可审计流水线与需求映射 |

## 五、更新检查表

每次更新题库时逐项检查：

- [ ] 新题能映射到一种岗位职责或可复现故障，而不是只因“网上常见”；
- [ ] 答案包含条件、证据、失败处理和边界；
- [ ] 版本敏感说法已用官方文档核对日期；
- [ ] 招聘样本未被写成比例、排名或薪资结论；
- [ ] 示例没有真实公司、客户、账号、域名、日志和数据；
- [ ] 失效链接已替换或标记存档；
- [ ] 旧答案如有错误，保留变更说明而不是静默覆盖历史。
