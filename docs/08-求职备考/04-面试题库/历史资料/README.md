# 历史面试资料

本目录保存仓库建立新版题库前的历史资料，目的是追踪内容演进：

- `大纲面试题-优化初稿-2525年10月23日.md`：较早的大纲版本；
- `大纲面试题-优化修订稿-2525年10月24日.md`：更新后的功能测试与职业规划大纲；
- `面试题答案-粗稿-1.0版.html`：旧版可视化答案页面。

历史文件名中的 `2525` 是旧文件原名，疑似年份笔误；为保留 Git 演进记录暂不重命名。

旧 HTML 中曾出现具体公司指向、看似真实的团队/版本/用户规模和第一人称经历措辞。当前版本不会原样发布这些段落：2025 第一版只保留净化后的题意，技术题优先复用现行评审答案，项目与职业题改为虚构练习框架或要求按本人真实情况回答。

新版备考请从[面试题库首页](../README.md)进入。

## 逐题迁移结果

构建器会解析：

- 初稿 175 个编号项；
- 修订稿 160 个编号项；
- HTML 160 个问答块；
- 合计 495 条历史记录。

每条记录都有稳定 ID、原文件定位、泛化题意、当前详解题 ID、匹配状态、隐私处理规则和复核标记。机器可读结果位于：

```text
apps/interview-bank/data/legacy-coverage.json
```

网站后端可通过以下接口查看：

```text
GET /api/v1/legacy-coverage
```

初稿中的 175 道题已逐题生成完整答案，并以 `2025 第一版（已复核）` 来源进入平台和离线题库。修订稿与旧 HTML 仍作为迁移证据参与 495 条覆盖审计；同义题优先关联同一份已评审知识，不直接复用未经核验的个人陈述。

机器可读的第一版评审数据位于：

```text
apps/interview-bank/data/legacy-2025-reviewed.json
```

## 使用原则

1. 用旧大纲检查是否遗漏经典问题；
2. 用新版专题获得经过重写的答案、解释、追问和误区；
3. 发现旧资料与官方规范冲突时，以官方规范和可复现实验为准；
4. 不向历史资料追加任何公司内部、客户或真实生产信息；
5. 不把旧答案中的第一人称叙述当作自己的经历；
6. 运行 `python apps/interview-bank/scripts/build_bank.py --check`，确保每个历史题意都有当前答案去向，并通过内容门禁。
