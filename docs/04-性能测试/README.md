# 阶段 4：性能测试与容量分析

目标：从业务负载和风险出发设计实验，用响应时间、吞吐、错误和资源证据形成可复核结论。

## 学习顺序

1. [性能测试方法](./01-性能测试方法.md)
2. [工具实践](./02-工具实践.md)

## 阶段项目

只对本地 [`demo-shop`](../../labs/demo-shop/README.md) 执行基线、负载和小规模压力实验：

```text
业务量与场景比例
  → 到达率/虚拟用户模型
  → 数据与预热
  → 阈值
  → 执行与监控
  → 瓶颈假设
  → 单变量复验
```

## 必须掌握

- p50/p95/p99、吞吐、并发、错误率和饱和度；
- 到达率与闭环虚拟用户模型；
- 基线、负载、压力、峰值和耐久测试差异；
- 客户端瓶颈、协调遗漏、预热和测量噪声；
- 应用、数据库、缓存、队列和依赖的时间线关联；
- 测试环境结论的适用边界。

## 完成证据

- [ ] 从业务量推导负载，不直接猜线程数；
- [ ] 阈值失败返回非零退出码；
- [ ] 报告同时包含负载、用户体验和资源指标；
- [ ] 至少一个瓶颈假设经过单变量复验；
- [ ] 明确不能外推到生产容量的原因。

完成后进入 [质量工程阶段](../05-质量工程/README.md)。
