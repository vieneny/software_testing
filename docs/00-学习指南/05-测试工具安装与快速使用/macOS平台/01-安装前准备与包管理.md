# macOS 安装前准备与包管理

## 1. 更新与确认系统

```bash
sw_vers
uname -m
arch
softwareupdate --list
```

更新系统前先备份个人学习项目。受公司管理的 Mac 应使用组织批准的软件中心和配置策略，不绕过 MDM、网络、终端防护和证书限制。

## 2. Terminal 与 shell

macOS 默认 shell 通常是 zsh：

```bash
echo "$SHELL"
zsh --version
```

常见配置文件：

| 文件 | 典型用途 |
|---|---|
| `~/.zprofile` | 登录 shell 的 PATH、Homebrew、JAVA_HOME、ANDROID_HOME |
| `~/.zshrc` | 交互 shell 别名、提示符和补全 |

本教程把持久环境变量放在 `~/.zprofile`。修改后：

```bash
source ~/.zprofile
```

先备份并理解原内容，不把同一段配置重复追加多次。

## 3. Xcode Command Line Tools

Git、Homebrew 和原生包编译常需要 Command Line Tools：

```bash
xcode-select --install
xcode-select -p
clang --version
```

如果弹出“已安装”，继续验证即可。注意：

- CLT 足够支撑 Git/Homebrew 和很多命令行构建；
- Appium iOS / XCUITest 必须安装完整 Xcode；
- 不要手工删除 `/Library/Developer/CommandLineTools` 作为日常排错手段。

## 4. Homebrew

[Homebrew 官方首页](https://brew.sh/)当前说明受支持环境为 macOS Sonoma 14+，支持 Apple Silicon 与 64 位 Intel。

官方安装命令：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

安装脚本会先说明将执行的操作并暂停。阅读输出后再继续。也可以使用官方 `.pkg` 安装器。

### 配置 PATH

Apple Silicon：

```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
```

Intel：

```bash
eval "$(/usr/local/bin/brew shellenv)"
```

把与你芯片匹配的命令加入 `~/.zprofile`。验证：

```bash
brew --version
brew --prefix
brew doctor
```

Apple Silicon 的 `brew --prefix` 应通常是 `/opt/homebrew`。如果显示 `/usr/local`，确认是不是在 Rosetta shell 中。

### 使用规则

```bash
brew search jq
brew info jq
brew install jq
jq --version
brew outdated
```

- 不用 `sudo brew ...`；
- 不手工修改 Homebrew Cellar 权限；
- 不同时维护 ARM 与 Intel 两套 Homebrew，除非有明确隔离方案；
- Cask 是上游桌面应用包装，许可证仍由上游决定；
- 第三方 Tap 先核对维护者和信任边界。

## 5. PATH

查看解析顺序：

```bash
printf '%s\n' "$PATH" | tr ':' '\n'
which -a python3
which -a node
which -a java
type -a git
```

推荐基础结构：

```bash
# Homebrew：二选一，按芯片
eval "$(/opt/homebrew/bin/brew shellenv)"

# JDK
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
export PATH="$JAVA_HOME/bin:$PATH"

# Android
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"

# MySQL 原生 PKG
export PATH="/usr/local/mysql/bin:$PATH"
```

只添加已安装工具。不要照抄后让不存在的路径长期占用 PATH。

## 6. Gatekeeper、签名与架构

优先使用签名/公证的官方 DMG/PKG。遇到“无法验证开发者”：

1. 核对下载域名；
2. 核对签名、校验值和官方发布说明；
3. 在系统设置的“隐私与安全性”查看具体阻止原因；
4. 只对明确可信的单个应用按官方说明处理。

不要全局关闭 Gatekeeper，不使用 `xattr -dr` 作为所有应用的通用安装步骤。

检查可执行文件架构：

```bash
file "$(command -v node)"
file "$(command -v python3)"
node -p 'process.arch' 2>/dev/null || true
python3 -c 'import platform; print(platform.machine())'
```

## 7. 文件与权限

工作区建议：

```text
~/workspace/           # 学习项目
~/tools/               # JMeter 等解压工具
~/test-data/           # 公开/合成数据
~/test-output/         # 临时报告与日志
```

不要把项目放在 iCloud Drive 等自动同步目录，除非已经确认 `.env`、数据库、报告和抓包不会被同步。

不要用：

```text
sudo pip install ...
sudo npm install -g ...
chmod -R 777 ...
```

解决普通项目依赖问题。Python 用虚拟环境；Node 用用户级官方安装或版本管理器；权限错误先找真实文件所有者和安装来源。

## 8. 下载校验

```bash
shasum -a 256 下载文件.dmg
shasum -a 512 apache-jmeter.tgz
spctl -a -vv -t install 下载文件.pkg
pkgutil --check-signature 下载文件.pkg
```

按工具官网提供的算法和签名方式核对。

## 9. 代理与证书

查看当前代理：

```bash
scutil --proxy
networksetup -listallnetworkservices
```

代理地址、PAC 和根证书应按组织的配置与凭据管理要求保存。安装 Reqable/Fiddler/Charles CA 前先读[代理证书与数据安全](../跨平台速查/03-代理证书与数据安全.md)。

## 10. 最小验收

```bash
sw_vers
uname -m
arch
xcode-select -p
git --version
brew --version
brew --prefix
brew doctor
```

如果暂不使用 Homebrew，也可跳过，但后续 macOS 命令会分别提供官方安装和 Homebrew 方式。
