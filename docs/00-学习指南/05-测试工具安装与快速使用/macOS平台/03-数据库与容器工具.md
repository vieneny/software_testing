# macOS 数据库与容器工具

## 1. 原生 MySQL 还是 Docker

| 方式 | 适合 | 注意 |
|---|---|---|
| 官方 MySQL DMG/PKG | 学 macOS 服务、配置和 CLI | 按 arm64/x86_64 下载；多版本升级更谨慎 |
| Docker MySQL | 学习项目、快速重置、团队复现 | Docker Desktop 资源和许可；镜像架构 |

不要同时让两个 MySQL 占用 `3306`。

## 2. MySQL Community Server

本仓库使用 MySQL 8.4 LTS 作为兼容基线。安装前核对：

- [MySQL macOS 安装手册](https://dev.mysql.com/doc/refman/8.4/en/macos-installation.html)
- [支持平台](https://www.mysql.com/support/supportedplatforms/database.html)
- [Community Server 下载](https://dev.mysql.com/downloads/mysql/)

官方支持矩阵当前重点支持 Apple Silicon。Intel 用户必须选择明确提供的兼容包，不把 Rosetta 可运行等同于官方支持。

### DMG/PKG 安装

1. 选择与芯片一致的 DMG；
2. 运行 PKG；
3. 记录临时 root 密码或按向导设置强密码；
4. 安装 Launch Daemon 和 Preference Pane（若包提供）；
5. 启动 MySQL；
6. 把 CLI 加入 `~/.zprofile`：

```bash
export PATH="/usr/local/mysql/bin:$PATH"
```

7. 新开 Terminal。

常见位置：

```text
/usr/local/mysql
/usr/local/mysql/data
/tmp/mysql.sock
```

验证：

```bash
mysql --version
mysqladmin -u root -p ping
mysql -u root -p -e 'SELECT VERSION();'
lsof -nP -iTCP:3306 -sTCP:LISTEN
```

### 建立学习账号

```sql
CREATE DATABASE test_learning
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;

CREATE USER 'test_learner'@'localhost'
  IDENTIFIED BY '请替换为本机强密码';

GRANT ALL PRIVILEGES ON test_learning.*
  TO 'test_learner'@'localhost';
```

应用不用 root。MySQL Community Server 为 GPLv2；闭源嵌入和分发需单独评估。

## 3. MySQL Workbench

按 [Workbench macOS 官方安装说明](https://dev.mysql.com/doc/workbench/en/wb-installing-mac.html)：

1. 下载与系统/芯片兼容的 DMG；
2. 拖到 `/Applications`；
3. 打开并建立 `127.0.0.1:3306` 连接；
4. 使用 `test_learner`；
5. Test Connection；
6. 运行 CRUD。

当前 Workbench 与 MySQL Server 有不同版本线，不能假设对新 Server 的全部管理功能都已支持。日志/配置常位于：

```text
~/Library/Application Support/MySQL/Workbench/
```

其中可能含连接历史，不上传。

## 4. DBeaver Community

[DBeaver 官方安装器](https://dbeaver.com/docs/dbeaver/Installation/)支持 macOS 11+，自带仅供 DBeaver 使用的 OpenJDK：

1. 选择 Mac 安装器；
2. 放入 `/Applications`；
3. 新建 MySQL Connection；
4. 首次连接时从官方仓库下载 JDBC Driver；
5. 使用合成学习账号。

工作区通常：

```text
~/Library/DBeaverData/
```

Workbench 与 DBeaver 二选一即可。DBeaver 多数据库更方便，Workbench 是 MySQL 官方客户端。

## 5. Docker Desktop

### 安装

按 [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/)：

1. 选择 Apple Silicon 或 Intel DMG；
2. 确认 macOS 属于当前及前两个受支持大版本；
3. 拖 `Docker.app` 到 `/Applications`；
4. 启动并完成权限设置；
5. CLI 符号链接可选择 `/usr/local/bin` 或用户 `$HOME/.docker/bin`；
6. 新开 Terminal。

若选择用户目录，在 `~/.zprofile` 加入：

```bash
export PATH="$HOME/.docker/bin:$PATH"
```

执行 `exec zsh` 或新开终端后再验证：

```bash
docker version
docker compose version
docker run --rm hello-world
```

Apple Silicon 上 Rosetta 2 不是 Docker Desktop 核心必需，但部分 amd64 工具仍可能需要。优先使用 arm64/multi-arch 镜像；使用 `--platform linux/amd64` 会引入仿真和性能差异。

Docker Desktop 对个人、教育、非商业开源和符合规模条件的小企业等免费；更大企业和政府使用可能需要付费订阅，以[官方条款](https://docs.docker.com/subscription/desktop-license/)为准。

### MySQL 容器实践

```bash
docker run --name mysql-learning \
  -e MYSQL_ROOT_PASSWORD=local-root-only \
  -e MYSQL_DATABASE=test_learning \
  -e MYSQL_USER=test_learner \
  -e MYSQL_PASSWORD=local-test-only \
  -p 3307:3306 \
  -d mysql:8.4

docker ps
docker logs mysql-learning
docker exec mysql-learning \
  mysqladmin ping -h 127.0.0.1 -u root -plocal-root-only
```

客户端连接 `127.0.0.1:3307`。

确认后停止/删除：

```bash
docker inspect mysql-learning --format '{{.Name}} {{.Config.Image}}'
docker stop mysql-learning
docker rm mysql-learning
```

### Redis 选修

```bash
docker run --name redis-learning -p 6380:6379 -d redis:7
docker exec redis-learning redis-cli PING
```

## 6. Mockoon 本地 Mock

按 [Mockoon 官方文档](https://mockoon.com/docs/latest/about/)安装桌面端：

1. 新建端口 `3001` 的环境；
2. 新建 `GET /health`；
3. 响应：

```json
{
  "status": "ok",
  "source": "local-mock"
}
```

4. 启动并验证：

```bash
curl -i http://127.0.0.1:3001/health
```

接口、抓包、k6 和 JMeter 后续都使用它，避免打扰公共服务。

## 7. 常见故障

| 现象 | 检查 |
|---|---|
| `mysql` 找不到 | `/usr/local/mysql/bin` 是否在 PATH |
| `Can't connect through socket` | 服务是否启动，socket 路径，尝试显式 `-h 127.0.0.1` |
| 3306 被占用 | `lsof -nP -iTCP:3306 -sTCP:LISTEN` |
| Workbench 启动失败 | macOS/芯片支持、签名、是否错误用了 Intel 包 |
| Docker daemon 不可用 | Docker.app 是否已启动、系统是否受支持 |
| arm64 镜像报错 | 镜像是否提供目标架构；不要先假设必须 Rosetta |
| 容器连接失败 | 宿主端口映射、日志、健康状态 |
| DBeaver Driver 下载失败 | 网络/代理和官方 Driver Manager |
