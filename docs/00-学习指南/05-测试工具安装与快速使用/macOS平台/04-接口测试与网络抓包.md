# macOS 接口测试与网络抓包

## 1. 工具层次

| 层次 | 工具 | 解决的问题 |
|---|---|---|
| API 构造与断言 | Apifox、Postman、curl | 请求、鉴权、参数、响应、场景 |
| HTTP(S) 调试代理 | Reqable、Fiddler Everywhere、Charles | 观察和改写客户端实际流量 |
| 网络数据包 | Wireshark | DNS、TCP、TLS、重传、RST |

一次只启用一个系统代理。先用 API 客户端定位协议问题，再根据证据进入抓包或网络层。

## 2. Apifox

按 [Apifox 官方下载文档](https://docs.apifox.com/download)选择 Apple Silicon 或 Intel 稳定版，拖到 `/Applications`。以下载页当前最低系统要求为准。

十分钟实践：

1. 新建只含公开数据的项目；
2. 新建 `baseUrl=https://postman-echo.com`，凭据只放本地值；
3. 发送 `GET {{baseUrl}}/get?course=software-testing`；
4. 断言状态码为 200；
5. 断言 `args.course` 为 `software-testing`；
6. 保存用例，加入测试场景；
7. 主动改错期望值，确认报告失败；
8. 恢复并再次执行。

继续阅读 [Apifox 快速上手](https://docs.apifox.com/getting-started)。

重要：

- 云端项目/远程值可能同步；
- 本地值、Vault、离线空间的边界以官方当前说明为准；
- 不导入公司的 OpenAPI、数据库、请求集合、环境变量和真实响应；
- 桌面 App 不要求加入 PATH。

## 3. Postman

按 [Postman 官方安装指南](https://learning.postman.com/docs/getting-started/installation/install-app/)选择 Intel 或 Apple Silicon 原生包，放到 `/Applications`。也可：

```bash
brew install --cask postman
```

十分钟实践：

1. 新建 Collection；
2. 发送 `GET https://postman-echo.com/get?course=software-testing`；
3. 添加：

```javascript
pm.test("状态码为 200", function () {
  pm.response.to.have.status(200);
});

pm.test("参数被原样返回", function () {
  const body = pm.response.json();
  pm.expect(body.args.course).to.eql("software-testing");
});
```

4. Collection Runner 运行；
5. 制造一次断言失败并查看详情。

桌面 API Client 可在部分场景不登录轻量使用；账号工作区通常涉及云能力。凭据使用本地值/Vault，先确认数据流向。

## 4. curl

```bash
curl -i 'https://postman-echo.com/get?course=software-testing'
curl -sS 'https://postman-echo.com/get?course=software-testing' | python3 -m json.tool
curl -v 'http://127.0.0.1:3001/health'
```

`-v` 会显示 Header 和连接信息，分享输出前检查 Cookie、Authorization、代理和域名。

## 5. 抓包工具选择

| 工具 | 系统/芯片 | 授权 | 适合 |
|---|---|---|---|
| Reqable | Apple Silicon / Intel DMG，macOS 11+（当前版本） | 非开源；Community/付费功能以官网为准 | API + 抓包一体、移动协同 |
| Fiddler Everywhere | macOS 12+，Apple Silicon / Intel | 账号、试用/订阅 | Live Traffic、Composer、Rules |
| Charles | Charles 5 支持 Apple Silicon；最低系统以下载器为准 | 30 天试用、商业许可 | Map Local/Remote、跨平台联调 |

先选一个，不需要同时信任三张根 CA。

## 6. Reqable

从 [Reqable 官方维护仓库](https://github.com/reqable/reqable-app)进入下载，选择芯片对应 DMG；或：

```bash
brew install --cask reqable
```

Reqable 自身文档中的简写 `brew install reqable` 在 Homebrew 能自动解析 Cask 时也可
工作；这里显式写 `--cask`，避免把桌面应用误认为 Formula。

官方仓库明确说明 Reqable 不是开源软件。

最小实践：

1. 关闭其他代理/VPN；
2. 启动 Reqable；
3. 先捕获 `http://127.0.0.1:3001/health`；
4. 核对方法、URL、状态码、耗时；
5. 保存为 API 并重放；
6. 如需 HTTPS，只在个人测试用户安装 Reqable CA；
7. 捕获 `https://example.com`；
8. 完成后关闭代理、删除 CA 和会话。

证书钉扎、mTLS、应用独立证书库或不走系统代理时，安装 CA 仍可能无法解密。

## 7. Fiddler Everywhere

按 [macOS 官方快速开始](https://www.telerik.com/fiddler/fiddler-everywhere/documentation/installation-and-setup/quickstart-macos)选择 Intel/Apple Silicon 包，放到 `/Applications`。

当前要求重点：

- macOS 12+；
- 约 400 MB 空间；
- 需要账号和互联网完成普通登录；
- 默认代理端口 `8866`；
- HTTPS 捕获需要管理员授权安装 CA 和修改系统代理。

最小实践：

1. Live Traffic 捕获 `https://example.com`；
2. Inspectors 查看请求/响应；
3. Composer 重放 GET；
4. Rules 对本机 Mock 注入合成错误；
5. 停止捕获；
6. 退出后执行 `scutil --proxy` 确认代理；
7. 不再使用时删除 Fiddler CA。

离线模式和企业管理能力属于特定商业套餐，以官方当前定价为准。

## 8. Charles

按 [Charles 官方安装说明](https://www.charlesproxy.com/documentation/installation/)下载，拖到 `/Applications`。Charles 5 支持 Apple Silicon；稳定版最低 macOS 未在安装页完整列出，应以下载器和官方支持为准。

默认代理端口通常为 `8888`。验证代理本身：

```bash
curl -x http://127.0.0.1:8888 http://example.com
```

HTTPS 实践：

1. Help → SSL Proxying → Install Charles Root Certificate；
2. Keychain Access 中只信任当前 Charles 生成的证书；
3. 只给 `example.com` 或自有测试域名启用 SSL Proxying；
4. 查看并 Repeat；
5. 退出后恢复 Network Proxies；
6. 按 [SSL Certificates](https://www.charlesproxy.com/documentation/using-charles/ssl-certificates/)删除 CA。

不要把 `*:*` 长期作为 SSL Proxying 范围。

## 9. Wireshark

### 安装

按 [Wireshark 官方用户指南](https://www.wireshark.org/docs/wsug_html_chunked/ChapterBuildInstall.html)：

1. 从官方下载 macOS DMG；
2. 拖 `Wireshark.app` 到 `/Applications`；
3. 安装 DMG 中的 `Install ChmodBPF.pkg`，让当前用户在受控权限下捕获；
4. 可按需安装系统路径包；
5. 启动稳定渠道版本。

不使用 `sudo Wireshark`。

### 十分钟实践

1. 选择当前活动接口；
2. 开始捕获；
3. 执行：

```bash
dig example.com
curl -I https://example.com
```

4. 停止；
5. 使用：

```text
dns
tcp.port == 443
tls
ip.addr == 目标IP
```

HTTPS 正文加密是正常结果。PCAP/PCAPNG 可能包含大量网络元数据，默认不保存和上传。

## 10. macOS 代理恢复

查看：

```bash
scutil --proxy
networksetup -listallnetworkservices
```

图形界面在“系统设置 → 网络 → 当前网络服务 → 详细信息 → 代理”。不要用不明确的脚本批量覆盖所有网络服务；先记录原值。
