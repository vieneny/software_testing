# macOS 编程语言与开发工具

## 1. Python

### 选择结论

不要修改或删除 `/usr/bin/python3`。它由 Apple/Xcode 工具链管理，不是个人项目解释器。

教程从 [Python macOS 官方下载页](https://www.python.org/downloads/macos/)安装 universal2 PKG，并用 Python 3.12 作为项目基线。universal2 同时支持 Apple Silicon 和 Intel；独立实验可另装官方当前版本。

### 安装

1. 下载签名、公证的 macOS 64-bit universal2 installer；
2. 运行 PKG；
3. 打开 `/Applications/Python 3.12/`；
4. 运行 `Install Certificates.command`，为该 Python 安装证书；
5. 新开 Terminal。

官方 PKG 通常安装到：

```text
/Library/Frameworks/Python.framework
```

并在 `/usr/local/bin` 创建命令链接。

验证：

```bash
which -a python3
python3 --version
python3 -m pip --version
python3 -c 'import sys, platform; print(sys.executable); print(platform.machine())'
```

### 项目虚拟环境

```bash
mkdir -p ~/workspace/python-smoke
cd ~/workspace/python-smoke
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install pytest
python -m pytest --version
```

新建 `test_smoke.py`：

```python
def test_python_environment():
    assert 2 + 2 == 4
```

运行：

```bash
python -m pytest -q
python -c 'import sys; print(sys.executable)'
```

常见问题：

- `python` 仍找不到：激活虚拟环境后使用，平时用 `python3`；
- pip 错配：始终使用 `python -m pip`；
- SSL 证书错误：确认执行的是对应 Python 目录下的 Install Certificates；
- 架构混用：比较 `uname -m`、`platform.machine()` 和二进制 `file` 输出。

## 2. PyCharm

从 [PyCharm 官方安装指南](https://www.jetbrains.com/help/pycharm/installation-guide.html)安装。推荐 JetBrains Toolbox：

1. 按 Apple Silicon 或 Intel 选择 Toolbox；
2. 在 Stable 渠道安装统一版 PyCharm；
3. 打开 `~/workspace/python-smoke`；
4. 项目解释器选择 `~/workspace/python-smoke/.venv/bin/python`；
5. 运行 pytest。

PyCharm 自带 JetBrains Runtime 21，运行 IDE 不需要另装 Java；项目仍需 Python。

当前版本的 macOS 最低要求可能很新，安装前查看官方系统要求。统一版核心 Python 功能免费，专业和 AI 功能按当前试用/订阅/配额执行。打开云 AI 功能前先确认数据政策，个人项目也不输入公司代码。

验证：

```bash
open -a PyCharm
```

或 Help → About 查看版本、架构和 Runtime。

## 3. Miniconda

### 什么时候安装

数据科学、AI、原生科学计算依赖或已有 `environment.yml` 时使用。常规接口/UI 自动化优先官网 Python + `venv`。

### 架构与支持

按 [Miniconda macOS 图形安装指南](https://www.anaconda.com/docs/getting-started/miniconda/install/mac-gui-install)、
[命令行安装指南](https://www.anaconda.com/docs/getting-started/miniconda/install/mac-cli-install)
和[系统要求](https://www.anaconda.com/docs/getting-started/miniconda/system-requirements)：

- Apple Silicon 使用 macOS arm64 安装器，当前要求 macOS 12.1+；
- 新的 macOS Intel `osx-64` 包和安装器已停止发布；
- Intel 机器只能使用官方归档中的最后兼容版本，不能承诺获得新包；
- 约需 400 MB 起步空间，实际环境远大于此。

两种安装方式选一种：

- 图形 PKG：当前官方安装器默认安装到 `/opt/miniconda3`，按安装器提示完成；
- 命令行 `.sh`：选择正确芯片的安装器，可把安装目录设为当前用户的
  `$HOME/miniconda3`，不需要把系统 Python 删除或覆盖。

不要同时装两份，也不要混合 arm64 与 x86_64 Channel。完成后：

```bash
conda init zsh
exec zsh
conda --version
conda info
conda create -n test-lab python=3.12 -y
conda activate test-lab
python -c 'import sys, platform; print(sys.executable); print(platform.machine())'
conda env export --from-history
conda deactivate
```

`conda` 工具开源，但默认 Anaconda 仓库受服务条款约束；组织使用前核对[官方条款](https://www.anaconda.com/legal/terms/terms-of-service)。`environment.yml` 不放 Token、私有仓库凭据和本机绝对路径。

## 4. Node.js 与 npm

### 安装

教程使用 Node 24 LTS；Current 只做独立实验。以下两条路线选一条：

**路线 A：官方 PKG。** 从 [Node.js 官方下载页](https://nodejs.org/en/download)
选择 LTS 和正确芯片的 PKG。适合只使用项目本地 npm 依赖；本教程的 Appium
也可按项目本地方式安装。

**路线 B：版本管理器。** 需要频繁切换 Node 版本或安装全局 Appium 时，使用
Node 官方下载页列出的版本管理器。以 `fnm` 为例：

```bash
brew install fnm
```

在 `~/.zshrc` 增加：

```bash
eval "$(fnm env --use-on-cd --shell zsh)"
```

然后新开终端：

```bash
fnm install 24
fnm default 24
fnm use 24
```

不要把 PKG、Homebrew Node 和版本管理器混在同一个 PATH 中。

验证：

```bash
which -a node npm
node -v
npm -v
npx -v
node -p 'process.execPath'
node -p 'process.arch'
npm config get prefix
```

十分钟实践：

```bash
mkdir -p ~/workspace/node-smoke
cd ~/workspace/node-smoke
npm init -y
npm install --save-dev vitest
npx vitest --version
```

不要使用 `sudo npm install -g` 解决权限错误。官方 PKG 若出现全局目录 `EACCES`，
优先使用项目本地依赖；确实需要全局 CLI 时改用版本管理器。若已有混装，先用
`which -a node`、`npm config get prefix` 和 `process.execPath` 找出实际来源。

Node 核心 MIT；npm 包各自许可。安装依赖前检查生命周期脚本、包维护状态和锁文件。

## 5. JDK

教程使用 [Eclipse Temurin JDK 21 LTS](https://adoptium.net/temurin/releases/)：

1. 选择 macOS、aarch64（Apple Silicon）或 x64（Intel）、JDK、PKG；
2. 安装到标准 JavaVirtualMachines 目录；
3. 在 `~/.zprofile` 设置：

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
export PATH="$JAVA_HOME/bin:$PATH"
```

4. 新开 Terminal。

验证：

```bash
/usr/libexec/java_home -V
echo "$JAVA_HOME"
java -version
javac -version
file "$JAVA_HOME/bin/java"
```

最小实践：

```bash
mkdir -p ~/workspace/java-smoke
cd ~/workspace/java-smoke
printf 'class Hello { public static void main(String[] args) { System.out.println("ok"); } }\n' > Hello.java
javac Hello.java
java Hello
```

这里的 `printf` 只是学习命令示例。仓库文件编辑仍应使用编辑器/Git。

Temurin 使用 GPLv2 + Classpath Exception。不要把 Oracle JDK 不同版本的许可笼统等同于 OpenJDK 发行版。

## 6. Git

安装方式：

```bash
xcode-select --install
```

可获得 Apple CLT 中的 Git；需要更新版本时：

```bash
brew install git
```

验证实际来源：

```bash
which -a git
git --version
git config --list --show-origin
```

个人配置：

```bash
git config --global user.name "你的公开学习身份"
git config --global user.email "你的个人公开邮箱或托管平台隐私邮箱"
git config --global init.defaultBranch main
```

Keychain 中保存的是访问凭据，提交中的姓名邮箱只是作者元数据。证书、SSH 私钥和访问令牌应由凭据存储管理，不应写入版本库。

## 7. VS Code

按 [VS Code macOS 官方指南](https://code.visualstudio.com/docs/setup/mac)选择 Universal、Apple Silicon 或 Intel DMG，拖到 `/Applications`。

安装 `code` 命令：

1. 打开 VS Code；
2. `Cmd+Shift+P`；
3. 执行 `Shell Command: Install 'code' command in PATH`；
4. 新开 Terminal。

```bash
code --version
which -a code
code ~/workspace/python-smoke
```

扩展只按需安装官方 Python/Pylance、Java 或 Playwright 扩展。VS Code 官方二进制的 Microsoft 许可与 Code-OSS 源码 MIT 不完全相同；扩展和 AI 助手还有独立许可与数据流。
