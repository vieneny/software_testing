# macOS 网页与移动端自动化

## 1. Web 自动化工具

| 工具 | 用途 | 浏览器策略 |
|---|---|---|
| Playwright Python | 新项目主线 | 安装与包版本匹配的 Chromium/Firefox/WebKit |
| Selenium Python | 企业存量和真实浏览器 | Selenium Manager 自动管理 Chrome/Edge Driver |
| Safari WebDriver | 真实 Safari 验证 | 系统自带 `/usr/bin/safaridriver` |

## 2. Playwright

安装前查看 [Playwright Python 官方要求](https://playwright.dev/python/docs/intro)。截至核对日，当前版本要求 macOS 14+。

```bash
mkdir -p ~/workspace/playwright-smoke
cd ~/workspace/playwright-smoke
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install pytest-playwright
python -m playwright install
python -m playwright install --list
```

新建 `test_example.py`：

```python
from playwright.sync_api import Page, expect


def test_example_domain(page: Page) -> None:
    page.goto("https://example.com/")
    expect(page).to_have_title("Example Domain")
    expect(page.get_by_role("heading", name="Example Domain")).to_be_visible()
```

运行：

```bash
python -m pytest -q
python -m pytest --headed
python -m pytest --browser chromium --browser webkit
```

Playwright 的 WebKit 是项目维护的测试构建，不等于真实 Safari。升级 Playwright 后重新运行浏览器安装命令。缓存通常位于：

```text
~/Library/Caches/ms-playwright
```

## 3. Selenium、Chrome、Edge 与 Safari

### Chrome / Edge

```bash
mkdir -p ~/workspace/selenium-smoke
cd ~/workspace/selenium-smoke
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade selenium
```

新建 `selenium_smoke.py`：

```python
from selenium import webdriver


driver = webdriver.Chrome()
try:
    driver.get("https://example.com/")
    assert driver.title == "Example Domain"
finally:
    driver.quit()
```

现代 Selenium 会调用 Selenium Manager。不要先手工安装 Driver：

```bash
which -a chromedriver msedgedriver
```

只有离线/固定版本时才按 [ChromeDriver 版本选择](https://developer.chrome.com/docs/chromedriver/downloads/version-selection)选择 `mac-arm64` 或 `mac-x64`，Edge 按[官方 WebDriver 文档](https://learn.microsoft.com/microsoft-edge/webdriver/)匹配浏览器前三段版本。

### Safari

Safari 自带 Driver：

```bash
/usr/bin/safaridriver --enable
```

最小脚本把上一段改成：

```python
driver = webdriver.Safari()
```

Safari WebDriver 通常一次只允许一个会话，自动化窗口与日常浏览数据隔离。参考 [Apple 官方 WebDriver 文档](https://developer.apple.com/documentation/webkit/testing-with-webdriver-in-safari)。

## 4. Android Studio、SDK 与 ADB

按 [Android Studio macOS 官方安装指南](https://developer.android.com/studio/install)选择 Apple Silicon 或 Intel DMG。

当前要求重点：

- macOS 12+；
- Studio 最低 8 GB RAM/8 GB 空间；
- Studio + Emulator 最低 16 GB RAM/16 GB 空间，建议 32 GB；
- Apple M1 或较新的 Intel CPU；
- Intel 支持正在逐步退出。

安装：

1. 拖到 `/Applications`；
2. 运行 Setup Wizard；
3. SDK Manager 安装目标 Platform、Platform-Tools、Build-Tools、Emulator、Command-line Tools (latest)；
4. 在 Device Manager 建 AVD：
   - Apple Silicon：`arm64-v8a`；
   - Intel：`x86_64`；
5. 启动并等待主屏幕。

在 `~/.zprofile`：

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
```

验证：

```bash
echo "$ANDROID_HOME"
adb version
adb devices -l
sdkmanager --list
emulator -list-avds
emulator -accel-check
```

`ANDROID_SDK_ROOT` 已弃用。

## 5. Android 真机

macOS 通常不需要额外 OEM USB Driver：

1. 个人测试手机开启开发者选项和 USB 调试；
2. 数据线连接；
3. 手机上的 RSA 授权；
4. 验证：

```bash
adb devices -l
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
```

`unauthorized` 时解锁并确认；多设备使用 `adb -s <serial>`。Android 11+ 可按 [ADB 官方文档](https://developer.android.com/tools/adb)使用 `adb pair` 无线调试，结束后在设备中忘记工作站。

## 6. Appium 3 与 UiAutomator2

[Appium 3](https://appium.io/docs/en/3.3/quickstart/install/)要求 Node `^20.19 || ^22.12 || >=24`、npm 10+。教程使用 Node 24 LTS。

本教程默认把 Appium 固定在独立项目中，避免官方 Node PKG 的全局 npm 目录权限
问题，也便于复现版本：

```bash
node -v
npm -v
mkdir -p ~/workspace/appium-server
cd ~/workspace/appium-server
npm init -y
npm install --save-dev appium@^3
npx appium --version
npx appium driver install uiautomator2
npx appium driver list --installed
npx appium driver doctor uiautomator2
```

后续所有 `npx appium` 命令都应在 `~/workspace/appium-server` 中运行。若 Node
由 `fnm` 等版本管理器安装，也可按官方方式全局安装 Appium；不要用
`sudo npm install -g` 绕过权限。

启动：

```bash
cd ~/workspace/appium-server
npx appium
```

默认：

```text
http://127.0.0.1:4723/
```

Python 客户端：

```bash
mkdir -p ~/workspace/appium-smoke
cd ~/workspace/appium-smoke
python3 -m venv .venv
source .venv/bin/activate
python -m pip install Appium-Python-Client pytest
```

新建 `android_settings_smoke.py`：

```python
from appium import webdriver
from appium.options.android import UiAutomator2Options


options = UiAutomator2Options().load_capabilities(
    {
        "platformName": "Android",
        "appium:automationName": "UiAutomator2",
        "appium:appPackage": "com.android.settings",
        "appium:appActivity": ".Settings",
        "appium:noReset": True,
    }
)

driver = webdriver.Remote("http://127.0.0.1:4723", options=options)
try:
    assert driver.current_package == "com.android.settings"
finally:
    driver.quit()
```

另开终端：

```bash
adb devices -l
python android_settings_smoke.py
```

## 7. 完整 Xcode

iOS 自动化不能只装 Command Line Tools。

先查看：

- [Xcode 系统要求](https://developer.apple.com/xcode/system-requirements/)
- [Xcode App Store](https://apps.apple.com/app/xcode/id497799835)
- [Xcode 资源与旧版本](https://developer.apple.com/xcode/resources/)

当前 Xcode 版本对 macOS 和芯片要求很高。Intel Mac 通常只能选择 Apple Developer Downloads 中与系统兼容的旧 Xcode，无法保证运行最新 iOS Simulator。

安装后：

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
xcode-select -p
xcodebuild -version
xcrun simctl list devices
```

首次启动 Xcode，接受许可并安装所需平台组件。Xcode 和 Simulator 占用大量磁盘，可在 Settings → Platforms 管理。

### Simulator 最小实践

1. Xcode → Open Developer Tool → Simulator；
2. 选择一个已安装 iOS Runtime 的设备；
3. 启动 Settings 或 Safari；
4. 执行：

```bash
xcrun simctl list devices booted
```

先用 Simulator 学习，不涉及真机签名。

## 8. XCUITest Driver

[Appium XCUITest Driver 系统要求](https://appium.github.io/appium-xcuitest-driver/latest/getting-started/system-requirements/)说明：

- 主线要求 macOS、完整 Xcode、Appium；
- Driver 10+ 对应 Appium 3；
- 主要支持最新两个 Xcode/iOS 大版本；
- Xcode、macOS、iOS 和 Driver 必须查兼容表。

安装和诊断：

```bash
cd ~/workspace/appium-server
npx appium driver install xcuitest
npx appium driver list --installed
npx appium driver doctor xcuitest
```

### Simulator 会话

Capability 示例：

```json
{
  "platformName": "iOS",
  "appium:automationName": "XCUITest",
  "appium:platformVersion": "填写已安装模拟器版本",
  "appium:deviceName": "填写 simctl 中设备名",
  "appium:bundleId": "com.apple.Preferences",
  "appium:noReset": true
}
```

系统 App 的 Bundle ID 可能随版本变化。先用 `xcrun simctl listapps booted` 查当前模拟器，再填写，不硬编码照抄。

## 9. iOS 真机

真机比 Simulator 多出安全和签名链：

1. Xcode 信任并识别设备；
2. iOS/iPadOS 16+ 打开 Developer Mode；
3. 开启 UI Automation；
4. WebView/Safari 场景开启 Web Inspector 和 Remote Automation；
5. WebDriverAgent (WDA) 使用有效 Provisioning Profile 签名；
6. 设备信任开发者证书。

XCUITest Driver 提供：

```bash
cd ~/workspace/appium-server
npx appium driver run xcuitest open-wda
```

打开 WDA Xcode 工程。付费 Apple Developer 账号可支持更自动的配置；免费 Apple Account 通常需要手工签名，证书有效期和能力有限。完整步骤参考：

- [Device Preparation](https://appium.github.io/appium-xcuitest-driver/latest/getting-started/device-setup/)
- [Provisioning Profile](https://appium.github.io/appium-xcuitest-driver/latest/getting-started/provisioning-profile/)

`xcodebuild` 65/70 应从签名、Team、Bundle ID、Provisioning、UDID、Xcode/iOS 兼容逐层排查。

## 10. Appium Inspector

从 [Appium Inspector 官方 Releases](https://github.com/appium/appium-inspector/releases)选择 macOS 架构包：

1. 启动 Appium Server；
2. Host `127.0.0.1`；
3. Port `4723`；
4. Path `/`；
5. 输入 W3C Capability；
6. 创建会话；
7. 优先 accessibility id、iOS Predicate/Class Chain、Android resource-id，避免绝对 XPath。

Inspector 与 Server 是两个独立应用。
