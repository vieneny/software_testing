# macOS 性能测试与测试报告

## 1. 安全前提

性能实验只对本机、自己部署的练习系统或明确授权环境执行。公共演示站只做 1 用户的功能烟雾，不做并发。

本章目标：

```text
http://127.0.0.1:3001/health
```

先按[数据库与容器工具](03-数据库与容器工具.md)启动 Mockoon。

## 2. JMeter

### 安装

[JMeter 官方入门](https://jmeter.apache.org/usermanual/get-started.html)要求 Java 8+；教程使用 JDK 21：

```bash
java -version
javac -version
echo "$JAVA_HOME"
```

1. 从 [JMeter 官方下载页](https://jmeter.apache.org/download_jmeter.cgi)下载 Binary Archive；
2. 核对 SHA-512/PGP；
3. 解压到无空格目录，如 `~/tools/apache-jmeter`；
4. 在 `~/.zprofile` 按实际目录设置：

```bash
export JMETER_HOME="$HOME/tools/apache-jmeter"
export PATH="$JMETER_HOME/bin:$PATH"
```

5. 新开 Terminal：

```bash
jmeter --version
```

### 最小实践

GUI：

```bash
jmeter
```

建立：

```text
Test Plan
└─ Thread Group（1 用户，1 循环）
   ├─ HTTP Request Defaults: 127.0.0.1:3001
   ├─ HTTP Request: GET /health
   ├─ Response Assertion
   └─ Summary Report（仅调试）
```

保存 `~/workspace/performance-smoke/health-smoke.jmx`。负载使用非 GUI：

```bash
mkdir -p ~/workspace/performance-smoke/report

jmeter \
  -n \
  -t ~/workspace/performance-smoke/health-smoke.jmx \
  -l ~/workspace/performance-smoke/result.jtl \
  -e \
  -o ~/workspace/performance-smoke/report
```

JMeter 是协议层工具，不渲染真实浏览器。负载前删除 View Results Tree 等高开销监听器；内存配置写入 `bin/setenv.sh`，不要直接改启动脚本。

## 3. k6

### 安装

按 [k6 官方安装文档](https://grafana.com/docs/k6/latest/set-up/install-k6/)：

```bash
brew install k6
k6 version
which -a k6
```

Homebrew 会选择芯片对应构建。也可使用官方 arm64/amd64 单文件或 Docker。

### 十分钟实践

新建 `health-smoke.js`：

```javascript
import http from "k6/http";
import { check } from "k6";

export const options = {
  vus: 1,
  duration: "5s",
  thresholds: {
    http_req_failed: ["rate==0"],
    http_req_duration: ["p(95)<500"],
  },
};

export default function () {
  const response = http.get("http://127.0.0.1:3001/health");
  check(response, {
    "status is 200": (r) => r.status === 200,
    "body contains ok": (r) => r.body.includes("ok"),
  });
}
```

```bash
k6 run health-smoke.js
```

k6 使用自己的 JavaScript runtime，不要求 Node.js，也不保证 npm 包兼容。k6 OSS 使用 AGPL-3.0；Grafana Cloud 是独立服务。默认匿名使用统计可按[官方说明](https://grafana.com/docs/k6/latest/set-up/usage-collection/)关闭：

```bash
K6_NO_USAGE_REPORT=true k6 run health-smoke.js
```

本教程默认本地运行，不上传结果。

## 4. 工具选择

| 维度 | JMeter | k6 |
|---|---|---|
| 运行时 | Java | 独立 runtime |
| 表达方式 | JMX/GUI + 插件 | JavaScript 代码 |
| 负载运行 | 必须 CLI | CLI |
| 适合 | 存量企业、录制、多协议 | 代码化、阈值、CI |
| macOS 芯片 | 随 JDK | 原生 arm64/amd64 |

先选一个形成“模型 → 脚本 → 指标 → 结论 → 复测”闭环。

## 5. Allure Report 3

新项目推荐 [Allure Report 3](https://allurereport.org/docs/v3/)项目本地安装：

```bash
cd ~/workspace/python-smoke
npm init -y
npm install --save-dev allure
npx allure --version

source .venv/bin/activate
python -m pip install allure-pytest
python -m pytest --alluredir allure-results --clean-alluredir
npx allure generate allure-results
npx allure open
```

Allure 3 通过 Node.js 运行，Apple Silicon/Intel 架构随 Node。

### Allure 2 存量

Allure 2 成熟且现有集成多，需要 Java：

```bash
brew install allure
allure --version
```

安装前阅读 [Allure 2 macOS 官方说明](https://allurereport.org/docs/v2/install-for-macos/)。不要让 Allure 2 Homebrew 命令与 Allure 3 npm 全局命令互相覆盖；新项目用 `npx allure` 更清晰。
