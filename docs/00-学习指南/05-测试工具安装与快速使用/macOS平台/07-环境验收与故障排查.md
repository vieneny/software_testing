## 3. 架构冲突

先检查当前 shell 和二进制：

```bash
uname -m
arch
brew --prefix
file "$(command -v python3)"
file "$(command -v node)"
file "$(command -v java)"
python3 -c 'import platform; print(platform.machine())'
node -p 'process.arch'
```

Apple Silicon 主线预期：

```text
shell: arm64
Homebrew: /opt/homebrew
Python/Node/JDK: arm64 或 universal2
Android AVD: arm64-v8a
```

如果某个 x86_64 工具只能通过 Rosetta 运行，把它隔离在明确的旧项目中，不用第二套 Homebrew 污染整个环境。

## 4. 分层排错

## 5. 高频故障矩阵

| 现象 | 常见原因 | 最小处理 |
|---|---|---|
| `brew` 找不到 | `brew shellenv` 未进 `.zprofile` | 按芯片配置并新开 Terminal |
| ARM Mac 显示 `/usr/local` brew | Rosetta shell/Intel Homebrew | 先确认 `arch`，不盲目双装 |
| Python 包装错位置 | pip 与解释器不一致 | `python -m pip` |
| Python HTTPS 证书错误 | python.org PKG 证书脚本未执行 | 运行对应版本的 Install Certificates |
| `npm -g` EACCES | 安装方式/全局 prefix 权限 | 修复 Node 管理方式，不 sudo |
| JAVA_HOME 与 `java` 不同 | PATH 旧版本优先 | `/usr/libexec/java_home -V` 后统一 |
| MySQL socket 错 | 客户端/服务 socket 不同 | 显式 `-h 127.0.0.1` 并核服务 |
| Docker amd64 很慢 | Apple Silicon 上仿真 | 使用 arm64/multi-arch 镜像 |
| Selenium Driver 错 | PATH 残留手工 Driver | 使用 Selenium Manager |
| Playwright 浏览器缺失 | 只装 Python 包 | `python -m playwright install` |
| `adb unauthorized` | 设备未确认 RSA | 解锁确认并重连 |
| AVD 启动失败 | 镜像架构/磁盘/Runtime | 选 arm64-v8a 或 x86_64 对应镜像 |
| Appium 找不到 Driver | 只装 Server | 安装/Doctor Driver |
| `xcodebuild` 不存在 | 只有 CLT | 安装完整 Xcode 并 `xcode-select` |
| XCUITest 65/70 | 签名/设备/目的地 | 按 WDA 签名链逐项验证 |
| HTTPS 抓包失败 | CA/域名/pinning | 只对自有 Debug 目标按官方处理 |
| 抓包退出后断网 | Network Proxy 残留 | 系统设置恢复，检查 `scutil --proxy` |
| Allure 版本混乱 | 2/3 命令重名 | `which -a allure`，新项目 `npx allure` |

## 8. 升级顺序

一次只升级一层：

```text
运行时 → 包管理器 → 框架 → Driver → 浏览器/平台 SDK → IDE
```

关键兼容对：

- macOS ↔ Xcode ↔ iOS；
- Apple Silicon/Intel ↔ Homebrew/运行时/AVD；
- Node ↔ Appium；
- Appium ↔ UiAutomator2/XCUITest；
- JDK ↔ Gradle/Maven/JMeter；
- Python ↔ pytest/Playwright/Appium Client；
- Browser ↔ Driver；
- Allure CLI ↔ adapter。

## 9. 卸载与清理

按原 DMG/PKG 或 Homebrew 官方方式卸载。拖走 `.app` 不一定移除：

- LaunchDaemon；
- CLI 符号链接；
- 配置和缓存；
- Network Proxy；
- Keychain CA；
- Android SDK/AVD；
- Appium Driver；
- Xcode Runtime/DerivedData；
- Docker 数据；
- MySQL 数据目录。

逐项确认明确路径，不批量删除 Keychain 根证书或用户 Library。
