# Windows 环境验收与故障排查

## 1. 一键自检

在本目录打开 PowerShell：

```powershell
Set-Location docs\00-学习指南\05-测试工具安装与快速使用\Windows平台
.\Windows环境自检.ps1
```

如果执行策略阻止脚本，只为当前进程放行：

```powershell
Set-ExecutionPolicy -Scope Process RemoteSigned
.\Windows环境自检.ps1
```

自检脚本检查系统、命令版本、Python 版本基线、环境变量和设备列表，不安装或
卸载软件。执行 `adb devices` 时，ADB 可能自动启动本机服务；可选工具显示
“未安装”不代表失败。脚本以 UTF-8 BOM 保存，可供 Windows PowerShell 5.1
和 PowerShell 7 正确读取中文。
输出可能包含用户名路径、设备标识和进程信息，分享前应检查并最小化这些字段。

## 3. 分层排错顺序

### Python

```text
命令解析 → Python 解释器 → 虚拟环境 → pip 目标 → 包导入 → pytest 配置 → 测试代码
```

证据：

```powershell
where.exe python
python -c "import sys; print(sys.executable); print(sys.version)"
python -m pip --version
python -m pip list
python -m pytest --collect-only
```

### Web 自动化

```text
Python 包 → Playwright/Selenium → 浏览器/Driver → 代理/策略 → 页面 → 定位器/等待
```

证据：

```powershell
python -m pip show playwright pytest-playwright selenium
python -m playwright install --list
where.exe chromedriver
where.exe msedgedriver
```

### Appium Android

```text
Node/npm → Appium Server → UiAutomator2 Driver
→ JAVA_HOME / ANDROID_HOME → ADB → 设备 → App → 定位器
```

证据：

```powershell
node -v
npm -v
appium --version
appium driver list --installed
appium driver doctor uiautomator2
java -version
$env:JAVA_HOME
$env:ANDROID_HOME
where.exe adb
adb devices -l
adb shell getprop ro.product.model
```

不要在看到 `SessionNotCreatedException` 后直接重装所有工具。先从 Appium Server 日志找到失败所在层。

### Docker/MySQL

```text
Windows/虚拟化 → WSL 2 → Docker daemon → 容器 → 端口 → MySQL 健康 → 用户授权
```

证据：

```powershell
wsl --version
docker version
docker ps -a
docker logs <容器名>
Get-NetTCPConnection -LocalPort 3306 -ErrorAction SilentlyContinue
mysql -h 127.0.0.1 -P 3306 -u test_learner -p
```

## 4. 高频故障矩阵

| 错误/现象 | 常见原因 | 最小处理 |
|---|---|---|
| 命令安装后仍找不到 | 旧终端、PATH 未更新 | 新开终端；`where.exe` 定位 |
| 命令显示旧版本 | PATH 前面有旧安装 | 记录来源，移除或调整明确目标 |
| `pip` 安装成功却无法 import | pip 与 Python 不属于同一解释器 | 始终 `python -m pip` |
| PowerShell 拒绝 `.ps1` | 执行策略 | 使用完整解释器路径或 Process 级 RemoteSigned |
| npm `.ps1` 被阻止 | PowerShell 脚本 shim | 先用 `npm.cmd`；不全局 Bypass |
| Java 工具找不到 `javac` | 装了 JRE 或 JAVA_HOME 错 | 安装 JDK，JAVA_HOME 指根目录 |
| Docker 无法启动 | WSL/虚拟化/系统版本 | 按层验证，不关闭系统安全 |
| 3306 连接失败 | 服务未启动/端口冲突 | 查服务、容器、端口和日志 |
| Selenium Driver 版本错 | PATH 残留旧 Driver | 使用 Selenium Manager，清理旧 PATH |
| Playwright 找不到浏览器 | 只装 Python 包 | `python -m playwright install` |
| `adb unauthorized` | 手机未确认 RSA | 解锁确认；撤销后重连 |
| 多个 Android 设备 | 未指定 serial | `adb -s <serial>`，Capability 指定 UDID |
| Appium 无可用 Driver | 只装 Server | 安装并 Doctor 对应 Driver |
| HTTPS 抓不到明文 | CA/域名/证书钉扎 | 只对自有测试目标按官方方式处理 |
| 抓包退出后断网 | 系统代理残留 | Windows 设置中恢复代理，删除临时 CA |
| JMeter GUI 卡死 | GUI 承担负载/监听器过重 | 非 GUI 运行，减少监听器 |
| Allure 报告混入旧结果 | 结果目录未清理 | 使用 `--clean-alluredir` 或独立目录 |

## 5. 端口检查

```powershell
Get-NetTCPConnection -State Listen |
  Sort-Object LocalPort |
  Select-Object LocalAddress, LocalPort, OwningProcess

Get-NetTCPConnection -LocalPort 3306 -ErrorAction SilentlyContinue
Get-NetTCPConnection -LocalPort 4723 -ErrorAction SilentlyContinue
Get-NetTCPConnection -LocalPort 3001 -ErrorAction SilentlyContinue
Get-Process -Id <OwningProcess>
```

先确认进程身份，不直接结束未知进程。

常见端口：

| 端口 | 常见用途 |
|---:|---|
| 3000/3001 | 前端或 Mock |
| 3306 | MySQL |
| 4723 | Appium |
| 5037 | ADB Server |
| 8080 | Web/代理常用 |
| 8866 | Fiddler Everywhere 默认 |
| 8888 | Charles 常见默认 |

## 6. 环境快照

在提问或复盘前保存经过脱敏的文本：

```powershell
Get-ComputerInfo |
  Select-Object WindowsProductName, WindowsVersion, OsBuildNumber, OsArchitecture

git --version
py list
node -v
npm -v
java -version
adb devices -l
appium driver list --installed
```

设备序列号、用户名、路径、代理、域名、Token 和公司信息要脱敏。不要把完整 `set`、`Get-ChildItem Env:` 或系统信息原样发到公开渠道。

## 7. 升级前后验证

升级一个工具，不同时升级整条链：

```text
记录旧版本与可回滚方式
→ 阅读 Release Notes / Migration Guide
→ 更新一个组件
→ 运行最小用例
→ 运行项目回归
→ 再更新下一个组件
```

关键兼容对：

- Python ↔ pytest / Playwright / Appium Client；
- Node ↔ Appium Server；
- Appium Server ↔ Driver；
- JDK ↔ Gradle/Maven/Spring/JMeter；
- Android SDK/ADB ↔ Emulator/真机；
- Browser ↔ Selenium Driver；
- MySQL Server ↔ Connector/Workbench；
- Allure CLI ↔ framework adapter。

## 8. 卸载与清理

软件本体通过“设置 → 应用 → 已安装的应用”或原包管理器卸载。卸载前先导出你自己的公开学习配置；不要备份公司连接。

额外检查：

- 用户/系统 PATH 是否残留；
- `JAVA_HOME`、`ANDROID_HOME` 是否仍指向已删除目录；
- `%USERPROFILE%\.appium` Driver 是否需要保留；
- `%LOCALAPPDATA%\Android\Sdk` 与 AVD 是否占用磁盘；
- Playwright 浏览器缓存；
- Docker 镜像、容器和卷；
- MySQL Windows 服务和数据目录；
- Fiddler/Reqable/Charles 根证书；
- Windows 系统代理。

不要用递归删除命令清理整个用户目录。逐项确认明确路径和数据归属。
