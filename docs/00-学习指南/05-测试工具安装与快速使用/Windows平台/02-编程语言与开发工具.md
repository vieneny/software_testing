# Windows 编程语言与开发工具

这一章安装 Python、PyCharm、Miniconda、Node.js、JDK、Git 和 VS Code。不要把 IDE 当成运行时，也不要让多个运行时同时抢占 PATH。

## 1. Python

### 用途

- pytest + requests 接口自动化；
- Playwright / Selenium Web 自动化；
- Appium 客户端；
- FastAPI 被测服务和 AI 测试工具。

### 选择结论

Python 官方在 Windows 上已把 **Python Install Manager** 作为主线。管理器来自 [python.org](https://www.python.org/downloads/windows/) 或 Microsoft Store，两种渠道提供相同核心能力。教程安装 Python 3.12 作为项目基线；你也可以并存安装官方当前版本做独立实验。

### 安装

1. 打开 [Python Windows 官方指南](https://docs.python.org/3/using/windows.html)；
2. 安装 Python Install Manager；
3. 新开 PowerShell；
4. 查看可安装/已安装运行时：

```powershell
py list
py install 3.12
py list
```

如果机器仍有旧版 Python Launcher，先用以下命令确认解析顺序：

```powershell
where.exe py
where.exe python
py list
```

不要盲目删除旧项目依赖的 Python。需要迁移时先记录每个项目解释器路径。

### 项目虚拟环境

```powershell
$WorkspaceRoot = Join-Path $HOME "workspace"
$ProjectRoot = Join-Path $WorkspaceRoot "python-smoke"
New-Item -ItemType Directory -Force -Path $ProjectRoot
Set-Location $ProjectRoot
py -V:3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python --version
python -m pip install --upgrade pip
python -m pip install pytest
python -m pytest --version
```

如果激活脚本被执行策略阻止，不要设置全局 `Bypass`。可以直接使用：

```powershell
.\.venv\Scripts\python.exe -m pip install pytest
.\.venv\Scripts\python.exe -m pytest --version
```

或只为当前 PowerShell 进程临时允许已签名/本地脚本：

```powershell
Set-ExecutionPolicy -Scope Process RemoteSigned
.\.venv\Scripts\Activate.ps1
```

### 十分钟实践

新建 `test_smoke.py`：

```python
def test_python_environment():
    assert 2 + 2 == 4
```

执行：

```powershell
python -m pytest -q
python -c "import sys; print(sys.executable); print(sys.version)"
python -m pip --version
```

### 常见问题

| 现象 | 检查 |
|---|---|
| Microsoft Store 自动打开 | 检查“应用执行别名”和 `where.exe python` |
| `pip` 装了但 import 不到 | 用 `python -m pip --version` 对比 `sys.executable` |
| `py` 显示旧行为 | `where.exe py`，检查旧 Launcher 是否优先 |
| 激活被禁止 | 使用虚拟环境内完整 Python 路径，或仅修改 Process 级策略 |
| 中文乱码 | 先确认终端、文件编码和程序输出，不全局乱改编码变量 |

Python 本体采用 PSF License；通过 pip 安装的每个包有独立许可证。

## 2. PyCharm

### 安装

官方推荐 [JetBrains Toolbox App](https://www.jetbrains.com/toolbox-app/) 管理安装、更新、回滚和多版本。也可从 [PyCharm 安装指南](https://www.jetbrains.com/help/pycharm/installation-guide.html)下载独立安装器。

当前 PyCharm 是统一产品：

- 核心 Python 功能可免费使用；
- 专业功能有试用/订阅边界，以当前授权页面为准；
- 自带 JetBrains Runtime，运行 IDE 不需要额外 JDK；
- Windows x64 和 ARM64 要选择对应安装包。

步骤：

1. 安装 Toolbox；
2. 在 Stable 渠道安装 PyCharm；
3. 新建或打开当前用户目录下的 `workspace\python-smoke`；
4. 解释器选择该项目下的 `.venv\Scripts\python.exe`；
5. 在内置终端执行 `python -c "import sys; print(sys.executable)"`；
6. 右键 `test_smoke.py` 运行 pytest。

验证：Help → About 查看版本和 Runtime。

常见误区：

- PyCharm 自带的 Runtime 不是项目 Python；
- 不要把一个全局解释器配置给所有不兼容项目；
- Toolbox 安装的命令脚本路径可在 Toolbox 设置中配置，通常位于当前用户目录；
- Web、数据库、远程开发和 AI 功能可能受授权、账号或配额限制。

## 3. Miniconda

### 什么时候安装

只有课程涉及数据科学、AI、本地科学计算包或已有 `environment.yml` 时再装。普通接口/UI 自动化优先 Python + `venv`。

### 重要支持与许可提醒

- 官方 Windows 安装器是 x86_64，不等于支持 Windows ARM64；
- 2026 年 Anaconda 已停止为 Windows 10 发布新的仓库包；
- `conda` 是开源工具，但默认 Anaconda 软件仓库受服务条款约束；组织使用前核对[官方条款](https://www.anaconda.com/legal/terms/terms-of-service)。

### 安装

根据 [Miniconda Windows 官方指南](https://www.anaconda.com/docs/getting-started/miniconda/install/windows-gui-install)：

1. 下载与系统匹配的安装器并核对 SHA-256；
2. 选择 **Just Me**；
3. 使用不含空格和特殊字符的用户目录；
4. 不勾选“Add Miniconda to PATH”；
5. 安装后打开 Miniconda Prompt；
6. 如需 PowerShell，执行 `conda init powershell` 后关闭并重开终端。

验证与实践：

```powershell
conda --version
conda info
conda create -n test-lab python=3.12 -y
conda activate test-lab
python -c "import sys; print(sys.executable)"
conda env export --from-history
conda deactivate
```

常见问题：

- `conda` 找不到：先用 Miniconda Prompt，不要急着全局加 PATH；
- Base 环境污染：项目依赖装到命名环境；
- pip/conda 混装：先装 conda 包，再在激活环境内用 `python -m pip` 补缺失包；
- PyCharm 解释器选错：选择目标环境中的 `python.exe`。

## 4. Node.js 与 npm

### 用途

- Appium 3 Server；
- React/Vue 前端；
- Playwright 的 JavaScript/TypeScript 路线；
- Allure 3 CLI；
- 各类前端测试工具。

### 安装

从 [Node.js 官方下载页](https://nodejs.org/en/download)选择 **LTS**，不要选择 Current 作为初学主线。核对[发布生命周期](https://nodejs.org/en/about/previous-releases)。

Windows 初学使用官方 x64 MSI：

1. 保留 Node.js runtime、npm 和 PATH 默认选项；
2. 不勾选不理解的“额外构建工具”；
3. 完成后重开 PowerShell。

```powershell
node -v
npm -v
where.exe node
where.exe npm
npm config get prefix
```

如果 PowerShell 阻止 `npm.ps1`，先执行 `npm.cmd -v` 验证 Node 安装，不要设置全局 `Unrestricted` 或 `Bypass`。

### 十分钟实践

```powershell
$WorkspaceRoot = Join-Path $HOME "workspace"
$ProjectRoot = Join-Path $WorkspaceRoot "node-smoke"
New-Item -ItemType Directory -Force -Path $ProjectRoot
Set-Location $ProjectRoot
npm init -y
npm install --save-dev vitest
npx vitest --version
```

项目依赖优先放 `devDependencies`，提交 `package-lock.json`，CI 使用 `npm ci`。`nvm-windows` 是社区项目，适合明确需要多版本时使用，但不能写成 Node 官方安装方式。

## 5. JDK

### 用途

- Spring Boot / Java 测试代码；
- Android 工具链；
- JMeter；
- Allure 2 存量 CLI。

### 安装

教程推荐 [Eclipse Temurin JDK 21 LTS](https://adoptium.net/temurin/releases/)：

1. 选择 Windows、x64/ARM64 对应架构、JDK、MSI；
2. 安装时允许设置 `JAVA_HOME` 和加入 PATH；
3. 新开 PowerShell。

```powershell
java -version
javac -version
where.exe java
$env:JAVA_HOME
Test-Path "$env:JAVA_HOME\bin\javac.exe"
```

`JAVA_HOME` 指向 JDK 根目录，不是 `bin`：

```text
正确：C:\Program Files\Eclipse Adoptium\jdk-21...
错误：C:\Program Files\Eclipse Adoptium\jdk-21...\bin
```

也可选择 Microsoft Build of OpenJDK。不要笼统假设不同 Oracle JDK 版本都可永久免费商用；学习项目优先使用许可清晰的 OpenJDK 发行版。

## 6. Git for Windows

官方方式：

```powershell
winget install --id Git.Git -e --source winget
git --version
where.exe git
```

或从 [Git for Windows 官方页面](https://git-scm.com/install/windows)下载安装器。建议保留：

- Git from the command line；
- bundled OpenSSH；
- Git Credential Manager；
- Windows 使用推荐的行尾默认值，具体项目由 `.gitattributes` 统一。

个人身份配置：

```powershell
git config --global user.name "你的公开学习身份"
git config --global user.email "你的个人公开邮箱或托管平台隐私邮箱"
git config --global init.defaultBranch main
git config --list --show-origin
```

提交作者信息不等于仓库登录凭据。SSH 私钥和访问令牌应由凭据存储管理，不应写入版本库。

## 7. VS Code

从 [VS Code Windows 官方指南](https://code.visualstudio.com/docs/setup/windows)下载安装。初学推荐 User Setup：

- 不需管理员权限；
- 默认装在当前用户目录；
- 自动加入 `code` 命令；
- 支持 x64 和 ARM64 对应构建。

```powershell
code --version
where.exe code
code (Join-Path $HOME "workspace\python-smoke")
```

最小扩展：

- Python（Microsoft）；
- Pylance（Microsoft）；
- Playwright Test（学习 JS/TS Playwright 时）；
- Extension Pack for Java（Java 路线时）。

只安装当前任务需要且发布者可信的扩展。VS Code 官方二进制遵循 Microsoft 产品许可；GitHub 上 `microsoft/vscode` 源码的 MIT 许可不等于所有官方二进制和扩展都采用 MIT。
