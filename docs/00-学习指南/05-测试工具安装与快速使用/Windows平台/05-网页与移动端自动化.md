# Windows 网页与移动端自动化

## 1. Web 自动化主线

| 工具 | 主线位置 | 驱动策略 |
|---|---|---|
| Playwright Python | 新项目主线 | 安装与 Playwright 版本匹配的浏览器 |
| Selenium Python | 企业存量与跨浏览器对照 | 优先 Selenium Manager |
| Chrome / Edge | 真实浏览器渠道验证 | 自动更新，避免手工旧 Driver 抢 PATH |

## 2. Playwright

当前 Playwright Python 官方系统要求会变化；安装前查看[官方安装文档](https://playwright.dev/python/docs/intro)。截至核对日，当前版要求 Windows 11+。

### 安装

```powershell
$WorkspaceRoot = Join-Path $HOME "workspace"
$ProjectRoot = Join-Path $WorkspaceRoot "playwright-smoke"
New-Item -ItemType Directory -Force -Path $ProjectRoot
Set-Location $ProjectRoot
py -V:3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install pytest-playwright
python -m playwright install
python -m playwright install --list
```

如果只学 Chromium：

```powershell
python -m playwright install chromium
```

### 十分钟实践

新建 `test_example.py`：

```python
from playwright.sync_api import Page, expect


def test_example_domain(page: Page) -> None:
    page.goto("https://example.com/")
    expect(page).to_have_title("Example Domain")
    expect(page.get_by_role("heading", name="Example Domain")).to_be_visible()
```

执行：

```powershell
python -m pytest -q
python -m pytest --headed
python -m pytest --browser chromium
```

升级 Playwright 后通常要重新安装匹配浏览器：

```powershell
python -m pip install --upgrade pytest-playwright playwright
python -m playwright install
```

浏览器缓存通常位于 `%USERPROFILE%\AppData\Local\ms-playwright`。不要把它提交 Git。

## 3. Selenium 与浏览器 Driver

现代 Selenium 使用 Selenium Manager 自动发现、下载和缓存匹配 Driver：

```powershell
$WorkspaceRoot = Join-Path $HOME "workspace"
$ProjectRoot = Join-Path $WorkspaceRoot "selenium-smoke"
New-Item -ItemType Directory -Force -Path $ProjectRoot
Set-Location $ProjectRoot
py -V:3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade selenium
```

新建 `selenium_smoke.py`：

```python
from selenium import webdriver


driver = webdriver.Chrome()
try:
    driver.get("https://example.com/")
    assert driver.title == "Example Domain"
finally:
    driver.quit()
```

执行：

```powershell
python .\selenium_smoke.py
```

不需要先下载 `chromedriver.exe`。如果失败：

```powershell
where.exe chromedriver
where.exe msedgedriver
```

删除 PATH 中的旧 Driver 前先确认它是否属于其他存量项目。离线或固定浏览器场景才按：

- [Chrome for Testing 与版本选择](https://developer.chrome.com/docs/chromedriver/downloads/version-selection)
- [Microsoft Edge WebDriver](https://learn.microsoft.com/microsoft-edge/webdriver/)

手工固定。Edge 浏览器与 EdgeDriver 前三段版本应一致。

## 5. Android Studio、SDK 与模拟器

按 [Android Studio Windows 官方安装指南](https://developer.android.com/studio/install)下载稳定版 `.exe`。

当前官方要求重点：

- 64 位 Windows 10 起，但持续支持以最新矩阵为准；
- Windows ARM CPU 目前不支持；
- 仅运行 Studio 最低约 8 GB RAM；
- 同时运行 Emulator 最低约 16 GB，建议 32 GB；
- 模拟器需要 VT-x/AMD-V 和 BIOS/UEFI 虚拟化；
- 预留至少 16～32 GB 磁盘。

安装：

1. 运行 `.exe`；
2. 完成 Setup Wizard；
3. SDK Manager 安装：
   - 一个目标 Android SDK Platform；
   - Android SDK Platform-Tools；
   - Android SDK Build-Tools；
   - Android Emulator；
   - Android SDK Command-line Tools (latest)；
4. Device Manager 建立一个与 CPU 架构匹配的 AVD；
5. 启动模拟器并等待主屏幕。

SDK 常见路径：

```text
%LOCALAPPDATA%\Android\Sdk
```

在用户环境变量中设置：

```text
ANDROID_HOME=%LOCALAPPDATA%\Android\Sdk
```

用户 PATH 添加：

```text
%ANDROID_HOME%\platform-tools
%ANDROID_HOME%\emulator
%ANDROID_HOME%\cmdline-tools\latest\bin
```

`ANDROID_SDK_ROOT` 已弃用，不作为新配置主线。

验证：

```powershell
$env:ANDROID_HOME
adb version
adb devices -l
sdkmanager --list
emulator -list-avds
```

## 6. 连接 Android 真机

1. 在个人测试手机启用开发者选项；
2. 开启 USB 调试；
3. 用支持数据传输的 USB 线连接；
4. Windows 如有需要，安装设备厂商官方 USB Driver；
5. 手机上确认 RSA 指纹；
6. 执行：

```powershell
adb devices -l
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
```

状态处理：

- `unauthorized`：解锁手机并确认 RSA；必要时撤销 USB 调试授权后重连；
- `offline`：`adb kill-server`、`adb start-server`，检查线缆；
- 多设备：每条命令加 `adb -s <serial>`；
- 找到多个 adb：`where.exe adb`，只保留当前 Platform-Tools 优先。

Android 11+ 可用官方无线调试：

```powershell
adb pair <设备IP>:<配对端口>
adb connect <设备IP>:<连接端口>
adb devices -l
```

仅在可信网络使用，结束后在设备中忘记工作站。

## 7. Appium 3 与 UiAutomator2

### 版本要求

[Appium 3 迁移指南](https://appium.io/docs/en/latest/guides/migrating-2-to-3/)要求 Node `^20.19.0 || ^22.12.0 || >=24.0.0` 和 npm 10+。教程使用 Node 24 LTS。

```powershell
node -v
npm -v
npm install -g appium
appium --version
```

Appium 只支持通过 npm 安装 Server。Server 不内置 Driver。

安装 Android Driver：

```powershell
appium driver install uiautomator2
appium driver list --installed
appium driver doctor uiautomator2
```

必须让 Doctor 的 required fixes 为 0。可选提示需要根据功能判断，不必为了“全绿”安装所有工具。

### 启动 Server

```powershell
appium
```

默认地址：

```text
http://127.0.0.1:4723/
```

Appium 2/3 默认不使用旧 `/wd/hub`。另开终端运行客户端。

### Python 客户端最小实践

```powershell
$WorkspaceRoot = Join-Path $HOME "workspace"
$ProjectRoot = Join-Path $WorkspaceRoot "appium-smoke"
New-Item -ItemType Directory -Force -Path $ProjectRoot
Set-Location $ProjectRoot
py -V:3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install Appium-Python-Client pytest
```

新建 `android_settings_smoke.py`：

```python
from appium import webdriver
from appium.options.android import UiAutomator2Options


options = UiAutomator2Options().load_capabilities(
    {
        "platformName": "Android",
        "appium:automationName": "UiAutomator2",
        "appium:appPackage": "com.android.settings",
        "appium:appActivity": ".Settings",
        "appium:noReset": True,
        "appium:newCommandTimeout": 60,
    }
)

driver = webdriver.Remote("http://127.0.0.1:4723", options=options)
try:
    print(driver.current_package)
    assert driver.current_package == "com.android.settings"
finally:
    driver.quit()
```

执行：

```powershell
adb devices -l
python .\android_settings_smoke.py
```

不同厂商可能修改设置 Activity。失败时先看 Appium Server 日志，再用：

```powershell
adb shell am start -n com.android.settings/.Settings
```

确认设备行为。

## 8. Appium Inspector

[Appium Inspector](https://github.com/appium/appium-inspector/releases) 是独立桌面客户端：

1. 下载官方 Windows 安装包；
2. 启动 Appium Server；
3. Remote Host: `127.0.0.1`；
4. Port: `4723`；
5. Path 留为 `/`；
6. 填写带 `appium:` 前缀的 W3C Capability；
7. Start Session；
8. 学习 accessibility id、resource-id、`-android uiautomator` 等 Android
   定位方式，不复制绝对 XPath 作为主线。

Inspector 不能替代 Server，也不能替代测试代码框架。

## 9. Appium 2 存量兼容

只有项目明确要求时才使用：

```powershell
npm install -g appium@2
```

UiAutomator2 Driver 5+ 只兼容 Appium 3。Appium 2 必须根据官方兼容说明固定 4.x Driver，不能执行无版本的最新版安装。迁移前分别记录：

```powershell
appium --version
appium driver list --installed
npm list -g --depth=0
```

不要在同一全局 npm 目录频繁覆盖 Appium 2/3。真正需要并存时用独立 Node 环境或项目本地依赖。

## 10. iOS 在 Windows 上的边界

Windows 不能本地运行 Xcode、iOS Simulator 和完整 XCUITest 工具链。可以：

- 学 WebDriver/Appium 协议和框架设计；
- 编写与 Android 共用的业务层代码；
- 连接经过批准的远程 macOS 执行节点。

不可以把第三方“iOS 模拟器”当成真实 Xcode Simulator。iOS 实践转到 [macOS 网页与移动端自动化](../macOS平台/05-网页与移动端自动化.md)。
