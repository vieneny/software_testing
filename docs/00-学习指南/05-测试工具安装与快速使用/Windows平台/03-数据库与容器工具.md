# Windows 数据库与容器工具

## 1. 先选原生还是容器

| 方式 | 适合 | 主要代价 |
|---|---|---|
| MySQL 原生 MSI | 学 Windows 服务、配置文件和本机运维 | 升级/卸载/多版本较复杂 |
| Docker MySQL | 学习项目、可重置环境、多项目隔离 | 需要 WSL 2、虚拟化和更多内存 |

初学 SQL 可以原生安装；本仓库复杂项目优先 Docker Compose。不要在同一台电脑同时让原生 MySQL 和容器 MySQL 占用 `3306`。

## 2. MySQL Community Server

### 版本选择

MySQL 官方当前同时维护 LTS 和 Innovation 系列。本仓库使用 **MySQL 8.4 LTS** 作为兼容基线。安装前在：

- [Community Server 下载页](https://dev.mysql.com/downloads/mysql/)
- [MySQL 支持平台](https://www.mysql.com/support/supportedplatforms/database.html)
- [Windows 安装手册](https://dev.mysql.com/doc/refman/8.4/en/windows-installation.html)

核对 Windows 和 CPU。2026-07 的支持矩阵只列 Windows 11 x86_64，不要把 Windows 10 或 ARM64 的“能运行”误写为官方支持。

### MSI 安装

1. 下载 8.4 LTS x64 MSI；
2. 运行安装器和 MySQL Configurator；
3. 配置类型选适合个人学习的 Development Computer；
4. TCP/IP 端口保持 `3306`，若冲突改成 `3307` 并记录；
5. 使用强 root 密码，只保存在本地密码管理器；
6. 注册 Windows 服务并允许自动启动；
7. 完成后用 MySQL CLI 验证。

MySQL 8.4+ 使用 MSI + Configurator。旧 **MySQL Installer** 主要管理 8.0 产品，不要用它维护 8.4/9.x。

若命令不在 PATH，可用完整路径或把当前版本 `bin` 加入用户 PATH：

```text
C:\Program Files\MySQL\MySQL Server 8.4\bin
```

验证：

```powershell
mysql --version
mysqladmin -u root -p version
mysql -u root -p -e "SELECT VERSION();"
Get-Service *mysql*
```

### 建立学习账号

登录 root 后：

```sql
CREATE DATABASE test_learning
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;

CREATE USER 'test_learner'@'localhost'
  IDENTIFIED BY '请替换为本机强密码';

GRANT ALL PRIVILEGES ON test_learning.*
  TO 'test_learner'@'localhost';

SHOW GRANTS FOR 'test_learner'@'localhost';
```

日常练习不使用 root 连接应用。密码不写入 Markdown、Git 或截图。

### 十分钟实践

```sql
USE test_learning;

CREATE TABLE test_case (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  title VARCHAR(100) NOT NULL,
  priority ENUM('P0', 'P1', 'P2') NOT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

INSERT INTO test_case(title, priority)
VALUES ('登录成功', 'P0'), ('密码错误', 'P1');

SELECT id, title, priority, created_at
FROM test_case
ORDER BY id;
```

## 3. MySQL Workbench

[MySQL Workbench](https://dev.mysql.com/downloads/workbench/) 是 MySQL 官方 GUI。当前 Workbench 仍有自己的版本和支持矩阵，不要仅因 Server 8.4/9.x 可安装就假定 Workbench 所有管理功能完全兼容。

安装：

1. 核对 [Workbench 支持平台](https://www.mysql.com/support/supportedplatforms/workbench.html)；
2. 下载 Windows x64 安装器；
3. 创建连接：
   - Hostname: `127.0.0.1`
   - Port: `3306`
   - Username: `test_learner`
4. Test Connection；
5. 打开 SQL Editor 执行上一节查询。

不要勾选保存真实公司密码。学习连接只指向本机。

## 4. DBeaver Community

DBeaver Community 适合同时学习 MySQL、PostgreSQL、SQLite 等 JDBC 数据源。
Redis 等 NoSQL 驱动属于其他 DBeaver 版本的能力，不纳入 Community 主线。
官方安装器自带仅供 DBeaver 使用的 OpenJDK，不需要为它单独安装 Java。

1. 从 [DBeaver 官方安装文档](https://dbeaver.com/docs/dbeaver/Installation/)进入下载；
2. Windows 10+ 使用安装器；
3. 新建 MySQL 连接；
4. 首次连接时核对并下载 JDBC Driver；
5. 使用 `test_learner`；
6. 在 SQL Editor 运行查询。

工作区通常位于 `%APPDATA%\DBeaverData\`。其中可能包含连接配置和脚本，不上传个人云端或 Git；设置 Master Password 并仍避免存公司凭据。

Workbench 与 DBeaver 二选一即可。

## 5. Docker Desktop

### 官方要求

先阅读 [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/)：

- 支持的 Windows 10/11 版本；
- WSL 2.1.5+；
- 64 位 CPU、SLAT 和 BIOS/UEFI 虚拟化；
- 至少 8 GB 内存；
- Windows ARM 构建的当前支持状态。

个人学习推荐 **per-user + WSL 2 backend**。

安装前：

```powershell
wsl --version
wsl --status
```

安装后启动 Docker Desktop，接受条款前阅读许可。Docker Desktop 对个人、教育、非商业开源和符合规模条件的小企业免费；较大企业、政府和某些专业用途需要付费订阅，以[官方许可说明](https://docs.docker.com/subscription/desktop-license/)为准。

验证：

```powershell
docker version
docker info
docker compose version
```

### 十分钟容器实践

```powershell
docker run --name mysql-learning `
  -e MYSQL_ROOT_PASSWORD=local-root-only `
  -e MYSQL_DATABASE=test_learning `
  -e MYSQL_USER=test_learner `
  -e MYSQL_PASSWORD=local-test-only `
  -p 3307:3306 `
  -d mysql:8.4

docker ps
docker logs mysql-learning
docker exec mysql-learning mysqladmin ping -h 127.0.0.1 -u root -plocal-root-only
```

客户端连接：

```text
Host: 127.0.0.1
Port: 3307
Database: test_learning
User: test_learner
Password: local-test-only
```

停止与恢复：

```powershell
docker stop mysql-learning
docker start mysql-learning
```

删除容器会删除未挂载的数据，先确认它确实只是本机练习容器：

```powershell
docker inspect mysql-learning --format "{{.Name}} {{.Config.Image}}"
docker stop mysql-learning
docker rm mysql-learning
```

### 可选 Redis 练习

```powershell
docker run --name redis-learning -p 6380:6379 -d redis:7
docker exec redis-learning redis-cli PING
docker exec redis-learning redis-cli SET learning:test ok
docker exec redis-learning redis-cli GET learning:test
```

## 6. Mockoon 本地 Mock

[Mockoon](https://mockoon.com/docs/latest/about/) 是本地 Mock API 工具，适合接口工具、抓包和性能脚本练习。

基本流程：

1. 从官方站点安装桌面端；
2. 新建环境，端口 `3001`；
3. 新建 `GET /health`；
4. 返回：

```json
{
  "status": "ok",
  "source": "local-mock"
}
```

5. 启动环境；
6. PowerShell 验证：

```powershell
Invoke-RestMethod http://127.0.0.1:3001/health
curl.exe -i http://127.0.0.1:3001/health
```

后续 Apifox、Reqable、k6 和 JMeter 都优先对这个本机接口实践。

## 7. 常见故障

| 现象 | 检查与处理 |
|---|---|
| 3306 被占用 | `Get-NetTCPConnection -LocalPort 3306`；选择原生或容器，不强杀未知进程 |
| MySQL 服务无法启动 | Event Viewer、MySQL error log、数据目录权限、配置语法 |
| Access denied | 用户、Host、密码和 `SHOW GRANTS`，不要用关闭鉴权解决 |
| Workbench 连不上容器 | 端口应为宿主映射 `3307`，Host 用 `127.0.0.1` |
| Docker 启动失败 | WSL 版本、虚拟化、内存、系统支持版本 |
| 容器立即退出 | `docker ps -a` 和 `docker logs <name>` |
| DBeaver 找不到 Driver | 检查网络、代理和 Driver Manager，不下载来源不明 JAR |
