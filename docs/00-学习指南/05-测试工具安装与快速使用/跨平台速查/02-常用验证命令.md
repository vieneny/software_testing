# 常用验证命令

安装完成后应验证“命令来源、版本、运行时路径、最小行为”四层。

## 1. Windows

### 系统与命令来源

```powershell
Get-ComputerInfo |
  Select-Object WindowsProductName, WindowsVersion, OsBuildNumber, OsArchitecture

Get-Command python -All
where.exe python
$env:Path -split ";"
```

### 基础运行时

```powershell
git --version
py list
python --version
python -c "import sys; print(sys.executable)"
python -m pip --version
conda --version
node -v
npm.cmd -v
java -version
javac -version
$env:JAVA_HOME
```

### 数据、容器和接口

```powershell
mysql --version
mysql -u root -p -e "SELECT VERSION();"
docker version
docker compose version
curl.exe -i http://127.0.0.1:3001/health
```

### Web 与移动自动化

```powershell
python -m playwright install --list
python -m pip show selenium
$env:ANDROID_HOME
adb version
adb devices -l
appium --version
appium driver list --installed
appium driver doctor uiautomator2
```

### 性能和报告

```powershell
k6 version
D:\tools\apache-jmeter\bin\jmeter.bat -v
npx allure --version
```

## 3. Python 解释器与 pip 必须对应

Windows：

```powershell
python -c "import sys; print(sys.executable)"
python -m pip --version
python -m site
```

macOS：

```bash
python -c 'import sys; print(sys.executable)'
python -m pip --version
python -m site
```

两条输出中的 Python 目录应属于同一虚拟环境。不要只执行裸 `pip`。

## 4. Node 全局命令位置

```bash
npm config get prefix
npm root -g
npm list -g --depth=0
```

Windows 再执行：

```powershell
where.exe node
where.exe npm
where.exe appium
```

macOS：

```bash
which -a node npm appium
```

## 5. Java

Windows：

```powershell
$env:JAVA_HOME
Test-Path "$env:JAVA_HOME\bin\javac.exe"
where.exe java
where.exe javac
```

macOS：

```bash
echo "$JAVA_HOME"
/usr/libexec/java_home -V
test -x "$JAVA_HOME/bin/javac" && echo "JDK 可用"
which -a java javac
```

`JAVA_HOME` 必须指向 JDK 根目录。

## 6. Android

```bash
adb devices -l
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb shell wm size
```

多设备时：

```bash
adb -s <serial> shell getprop ro.product.model
```

预期状态是 `device`。`unauthorized` 和 `offline` 都不能开始 Appium 会话。

## 7. 端口与进程

Windows：

```powershell
Get-NetTCPConnection -State Listen |
  Select-Object LocalAddress, LocalPort, OwningProcess

Get-Process -Id <PID>
```

macOS：

```bash
lsof -nP -iTCP -sTCP:LISTEN
lsof -nP -iTCP:4723 -sTCP:LISTEN
ps -p <PID> -o pid,ppid,command
```

## 8. 验收不是“全有”

没有安装的可选工具可以跳过。正确验收是：

- 当前学习任务所需工具全部可用；
- 版本属于支持范围；
- 同一个项目没有混用运行时；
- 最小公开/本机实验成功；
- 知道怎样还原代理、证书、设备和临时服务。
