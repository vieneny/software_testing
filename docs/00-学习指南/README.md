# 阶段 0：环境与测试基础

目标：建立后续所有阶段共用的命令行、网络、数据库、Python、Git 和工具环境，不要求第一天安装全部测试工具。

## 阶段任务

- 用 Git 完成修改、差异检查、提交和分支合并；
- 用命令行检查进程、端口、文件、环境变量和退出码；
- 用 curl 解释一次 HTTP 请求与响应；
- 用 SQL 完成过滤、关联、聚合和事务实验；
- 用 Python 读取 JSON、校验字段并返回正确退出码；
- 建立按阶段安装工具的版本清单。

## 完成证据

- [ ] 一份本机环境自检结果；
- [ ] 一个可重复创建的 Python 虚拟环境；
- [ ] 一次主动失败的命令或脚本及定位记录；
- [ ] 一次包含 `status`、`diff`、`commit` 的 Git 操作；
- [ ] 能说明代理、证书、PATH、端口和权限分别会造成什么问题。

完成后进入 [功能测试阶段](../01-功能测试/README.md)。
