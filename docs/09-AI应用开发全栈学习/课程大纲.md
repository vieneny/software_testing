## 本次已整理范围

```text
01 Java&AI 基础
  -> 02 JavaWEB 和单体架构
  -> 03 尚品甄选项目
```

这三块形成一个可独立验收的开发基础闭环：先掌握 Java 和数据库，再完成 Web/单体工程能力，最后通过商城业务理解鉴权、缓存、事务、消息和支付等真实系统问题。后续 04～13 模块会继续放在本目录内，保持“一个课程整体”的组织方式，不拆入测试阶段或面试题阶段。

## 单模块验收

- 能脱离笔记解释本模块的核心概念、边界和常见失败；
- 能在本机使用临时环境和合成数据完成一个最小练习；
- 能画出请求、数据、缓存和消息的关系，并写出至少一条测试思路；
- 能记录运行命令、失败现象、定位依据和修复结论；
- 能说明本模块使用到的数据、配置和外部依赖，并保持练习可复现。
