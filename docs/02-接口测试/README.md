# 阶段 2：接口测试与接口自动化

目标：从理解 HTTP 和手工探索开始，最终交付可重复、可诊断、能进入 CI 的接口自动化项目。

## 学习顺序

1. [网络请求与接口基础](./01-网络请求与接口基础.md)
2. [接口测试实战](./02-接口测试实战.md)
3. [接口自动化测试框架](./03-接口自动化测试框架.md)
4. [接口自动化项目全流程](./04-接口自动化项目全流程.md)

## 阶段项目

使用 [`labs/demo-shop`](../../labs/demo-shop/README.md) 完成稳定本地业务链，再用 [`labs/automation-practice`](../../labs/automation-practice/README.md) 学习 Client、Schema、公共 smoke 和框架分层。

```text
查商品 → 创建订单 → 查询订单 → 重复幂等请求 → 清理/重置
```

## 必须覆盖

- 协议：方法、状态码、头、媒体类型、缓存；
- 结构：JSON Schema、必填字段、类型和兼容性；
- 业务：金额、库存、状态迁移和错误语义；
- 安全：鉴权、越权、输入和信息暴露；
- 数据：幂等、并发、清理和最终一致性；
- 工程：配置、Client、Service、Fixture、日志和 CI。

## 完成证据

- [ ] curl/Postman 探索记录与自动化实现对应；
- [ ] 正常、边界、异常、权限和幂等用例；
- [ ] 用例可乱序、重复运行；
- [ ] 请求失败能定位 DNS、连接、TLS、超时、协议或业务层；
- [ ] PR 只运行本地确定性检查，公共实例单独显式运行。

完成后进入 [UI 自动化阶段](../03-UI自动化/README.md)。
