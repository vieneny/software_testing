# 人工智能测试与模型评测开源项目

本页覆盖五类能力：

1. 测试 LLM/RAG 应用；
2. 建立模型与多模态 Benchmark；
3. 验证经典机器学习模型、数据和漂移；
4. 建设可重复评测流水线；
5. 把评测结果接入 CI 和发布决策。

AI 测试不是对聊天窗口多问几句。核心交付物是版本化数据集、明确指标、可复现执行、人工校准、误差分析和可执行门禁。

## 一、LLM 与 AI 应用评测主线

| 项目 | 里面有什么 | 可以做什么、学什么 | 定位 |
|---|---|---|---|
| [Promptfoo](https://github.com/promptfoo/promptfoo) | YAML/JavaScript 测试矩阵、Provider、断言、评分器、Prompt/模型比较、RAG/Agent 测试、红队和 CI | 建版本化评测集，组合确定性断言与模型评分，做跨模型/Prompt 回归和安全门禁 | **AI 应用测试主线，L2→L3** |
| [DeepEval](https://github.com/confident-ai/deepeval) | pytest 风格测试、G-Eval、相关性、幻觉、RAG、对话、Agent 工具正确性、自定义指标和合成数据 | 把 AI 质量写成 Python 测试；学习阈值、Judge 校准、随机性和失败解释 | **Python 主线，L2→L3** |
| [Ragas](https://github.com/vibrantlabsai/ragas) | RAG/LLM 指标、测试集生成、自定义评价器、实验与生产反馈 | 学检索与生成分层、忠实度、上下文质量和黄金集；对 RAG 做 A/B 实验 | **RAG 主线，L2→L3** |
| [Inspect AI](https://github.com/UKGovernmentBEIS/inspect_ai) | 英国 AI Security Institute 的 task、dataset、solver、scorer、tool、sandbox 和日志框架 | 学标准化、可复现、受控执行和多次运行；开发自己的评测包 | **模型/Agent 高阶主线，L3** |
| [Inspect Evals](https://github.com/UKGovernmentBEIS/inspect_evals) | Inspect AI 可运行评测集合，覆盖能力、安全、Agent 和其他公开 Benchmark | 阅读成熟评测如何定义数据、solver、scorer、版本和限制；不盲目跑全量 | **任务实现参考，L3** |
| [Giskard OSS](https://github.com/Giskard-AI/giskard-oss) | v3 重写后的 `giskard-checks`、`giskard-scan`、动态多轮 Agent 场景、Judge 与红队 | 测黑盒 Agent、生成动态场景、做注入/泄漏扫描；理解测试生成与人工真值差异 | **前沿选修，L3** |

### Giskard 2026 状态

- 当前官方仓库是 `Giskard-AI/giskard-oss`；
- v3 是面向动态、多轮 Agent 测试的重写；
- 截至 2026-07-27，`giskard-checks` 与 `giskard-scan` 均为 **Beta**；
- `giskard-rag` 仍是 **Planned**，旧 RAGET/v2 Scanner 尚处迁移期；
- v2 不再积极维护；
- 不应把旧 v2 教程原样当成 v3 能力；使用 Beta 包必须固定版本并准备迁移。

## 二、通用模型 Benchmark Harness

这些项目更偏“评模型”，不是直接替业务 App 做端到端验收。

| 项目 | 里面有什么 | 可以做什么、学什么 | 定位 |
|---|---|---|---|
| [lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness) | 大量公开 Benchmark、YAML/Jinja 任务、few-shot、后处理、HF/vLLM/API 后端和逐样本日志 | 学任务定义、Prompt 版本、答案提取、可复现模型横评和自定义指标 | **模型评测主线，L3** |
| [Lighteval](https://github.com/huggingface/lighteval) | Hugging Face 评测工具、众多多语言任务、Inspect/Accelerate/vLLM/SGLang 后端和逐样本结果 | 学多后端执行、任务/指标定制和样本级误差分析 | **模型评测推荐，L3** |
| [EvalScope](https://github.com/modelscope/evalscope) | LLM、VLM、AIGC 评测与性能 Benchmark，并可接多种后端 | 学国内/多模态模型评测、统一任务配置和结果管理 | **国内生态选修，L3** |
| [HELM](https://github.com/stanford-crfm/helm) | 能力、安全、偏差、效率等整体评测、场景/适配器/指标和结果 UI | 阅读“全面而透明”的评测设计；官方已说明 2026-06-01 起进入维护模式 | **迁移/研究参考，L3** |
| [OpenAI Evals](https://github.com/openai/evals) | 经典 Eval Registry、模板、数据和自定义评测 Harness | 阅读早期评测注册与 Benchmark 结构；不把开源仓库和退出中的 hosted Evals 产品混为一谈 | **历史参考，L3** |
| [Hugging Face Evaluate](https://github.com/huggingface/evaluate) | 传统指标、比较、测量和数据集接口 | 维护经典 NLP/ML 项目；官方对新 LLM 评测推荐 Lighteval | **存量参考，L2** |

模型排行榜不能直接回答“我的产品是否可上线”。公共 Benchmark 应防止：

- 数据泄漏和训练污染；
- Prompt/模板差异；
- 版本、量化、采样和推理后端不一致；
- 只报平均分而隐藏关键切片；
- 反复调参直到测试集最好；
- 用学术题替代真实业务、可靠性和安全测试。

## 三、多模态评测

| 项目 | 里面有什么 | 可以做什么、学什么 | 定位 |
|---|---|---|---|
| [VLMEvalKit](https://github.com/open-compass/VLMEvalKit) | 大量视觉语言模型、图片/图表/OCR 等 Benchmark、统一推理和评判 | 学 VLM 接入、任务映射、Judge、结果提交和多模态失败分类 | **VLM 推荐，L3→L4** |
| [LMMS-Eval](https://github.com/EvolvingLMMs-Lab/lmms-eval) | 文本、图像、视频、音频任务，多模型后端、批处理、统计和结果管理 | 建多模态模型横评；分析 OCR、空间、视频时序和音频理解问题 | **多模态主线，L3→L4** |
| [SWE-bench Multimodal](https://github.com/SWE-bench/SWE-bench) | 包含图片上下文的软件 Issue 和容器化补丁验证 | 研究视觉输入如何影响 Coding Agent；资源要求高，先做小样本 | **Agent/多模态高级，L4** |

多模态作品至少按以下切片报告：

- 清晰度、分辨率、压缩、旋转、遮挡；
- OCR 字体、语言、表格和图表；
- 单图、多图与图文交错；
- 视频长度、关键帧和时序；
- 音频口音、噪声、重叠和流式；
- 错误是感知、识别、推理、知识还是输出格式问题。

## 四、RAG 诊断和评测数据

| 项目 | 里面有什么 | 可以做什么、学什么 | 定位 |
|---|---|---|---|
| [RAGChecker](https://github.com/amazon-science/RAGChecker) | 整体指标、Retriever/Generator 诊断和 Claim 级分析 | 把失败归因到检索或生成，输出可操作优化建议 | **RAG 诊断选修，L3** |
| [ARES](https://github.com/stanford-futuredata/ARES) | 合成查询、分类器/Judge、少量标注和 Prediction-Powered Inference | 学带置信区间的 RAG 评测和少量人工标签利用 | **统计进阶，L4** |
| [RAGTruth](https://github.com/ParticleMedia/RAGTruth) | RAG 回答及样本/词级人工幻觉标注数据 | 研究幻觉分类、标注一致性和 Judge 校准 | **数据集参考，L3** |
| [RAGBench](https://github.com/rungalileo/ragbench) | 多数据集和 RAG 评价器对照资源 | 比较自动评价器与人工标注的一致性，不迷信单一指标 | **评测研究参考，L3** |

RAG 最小评测组合：

```text
检索：Recall@k / MRR / nDCG / 元数据过滤
生成：事实与引用、无答案拒答、冲突处理
端到端：任务成功、延迟、成本和安全
人工：关键切片复核、错误类型和标注一致性
```

## 五、经典机器学习、数据与公平性

AI 测试不等于只测 LLM。招聘中的算法测试、模型评测和多模态岗位仍可能要求经典 ML 能力。

| 项目 | 里面有什么 | 可以做什么、学什么 | 定位 |
|---|---|---|---|
| [Evidently](https://github.com/evidentlyai/evidently) | ML/LLM 数据与质量评测、漂移、测试、报告和监控 | 验证数据漂移、模型指标和生成式应用质量；建立线上/离线对照 | **ML 质量推荐，L2→L3** |
| [Deepchecks](https://github.com/deepchecks/deepchecks) | 数据、模型和持续验证检查套件 | 学训练/验证数据问题、模型表现切片和回归检查 | **ML 选修，L3** |
| [whylogs](https://github.com/whylabs/whylogs) | 数据画像、统计摘要和隐私友好的数据日志 | 学数据质量、漂移和低存储画像；仍要审查是否接入外部服务 | **数据观测选修，L3** |
| [Great Expectations](https://github.com/great-expectations/great_expectations) | 数据资产、Expectation、Validation 和文档 | 为训练、评测和 RAG 数据建立类型、范围、完整性、唯一性和引用规则 | **数据质量选修，L2→L3** |
| [Adversarial Robustness Toolbox](https://github.com/Trusted-AI/adversarial-robustness-toolbox) | 逃逸、投毒、模型提取、推断攻击与防御，覆盖图像、表格、音频、视频等 | 学经典 ML 对抗威胁、红蓝队和鲁棒性评测 | **算法安全进阶，L3→L4** |
| [Fairlearn](https://github.com/fairlearn/fairlearn) | 群体公平性指标、Dashboard 思想和缓解算法 | 按人群切片评估服务质量差异；理解公平是社会技术问题，不是单一分数 | **公平性选修，L3** |
| [AIF360](https://github.com/Trusted-AI/AIF360) | 数据/模型公平指标、解释和偏差缓解算法 | 对照多种公平定义和取舍；建立偏差测试报告 | **研究选修，L3→L4** |
| [MLflow](https://github.com/mlflow/mlflow) | 实验、模型/Prompt、Trace、评测、注册和 AI Gateway 等平台能力 | 学评测集、模型、Prompt、结果和版本的统一治理 | **评测平台进阶，L3** |

## 六、怎么选择

| 目标岗位 | 第一选择 | 第二阶段 | 高阶阅读 |
|---|---|---|---|
| 传统测试 + AI 提效 | Promptfoo 或 DeepEval | 小型 Ragas；AI 辅助效果实验 | Giskard Checks |
| AI 应用测试 | Promptfoo + DeepEval | Ragas + Phoenix/Langfuse | Inspect AI |
| 模型评测 | Lighteval 或 lm-eval | Inspect AI + 多模态工具 | HELM/ARES |
| 多模态评测 | VLMEvalKit 或 LMMS-Eval | 自建公开小数据集 | SWE-bench Multimodal |
| 评测平台 | Inspect AI + MLflow/Phoenix | 任务队列、数据集和 OTel | 多后端分布式执行 |
| 经典算法测试 | Evidently + Deepchecks | ART + Fairlearn | AIF360 |

## 七、建议形成的作品

### 作品一：RAG 质量回归

- 50～100 条公开/合成黄金集；
- 正常、无答案、冲突、过期、注入和权限切片；
- 检索 Recall@k + 引用/忠实度 + 人工复核；
- Promptfoo/DeepEval 自动回归；
- Ragas 或 RAGChecker 分层诊断；
- 每次变更输出质量、延迟和成本差异。

### 作品二：模型横评

- 选一个公开小型任务；
- 固定数据、Prompt、采样、后端和版本；
- 用 Lighteval/lm-eval 执行；
- 保存逐样本结果；
- 按难度、语言和任务类型切片；
- 写置信区间、限制和可能污染。

### 作品三：多模态评测

- 自建仅含公开素材的小数据集；
- OCR、图表、空间、拒答和安全任务；
- 使用 VLMEvalKit 或 LMMS-Eval；
- 多次运行并分类感知/推理/格式错误；
- 不上传公司截图、产品界面或内部文档。

### 作品四：经典 ML 质量

- 使用公开数据训练一个小模型；
- Great Expectations 验证数据；
- Deepchecks/Evidently 检查数据和模型；
- Fairlearn 做人群切片；
- ART 做有限对抗实验；
- 输出准确率之外的鲁棒性、公平性和漂移报告。
